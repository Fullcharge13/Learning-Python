# 장 따로 불러오기 설계 (리아와 파이썬! v0.3)

- 작성일: 2026-10-30 · 상태: **확정**(사용자 결정: 「필요할 때 불러오기」 + 「설치할 때 전부 미리 받기」)
- 배경: v0.2에서 배포 index.html이 651.8KB가 됐다. 장마다 약 20KB씩 늘어나 11장 무렵 700KB 상한(C28)을 넘는다.

## 1. 파일 나누기

| 배포 파일 | 담는 것 |
|---|---|
| `index.html` | 앱 코드·화면 + **레슨 목록**: 장 번호와 제목, 레슨 id·title·goal·summary·isExam, 레슨이 쓰는 개념 id 목록 |
| `lessons/chN-<지문8자>.json` | 장 하나의 레슨 전체(cards, items) |
| `lessons/index.json`은 두지 않음 | 장 파일 이름은 빌드 때 index.html 안 표(`RIA_CHAPTER_FILES`)에 박는다 |

- 작성 형식(`data/lessons/chN.js`), 점검기, README 생성기, 경제 시뮬레이션은 바뀌지 않는다. `build.py`만 나눈다.
- 크기 목표: index.html ≤ 700KB(그대로). 장 파일에는 개별 상한을 두지 않고 크기만 출력한다.

## 2. 앱에서 가져오기

- `src/lessondata.js`의 `getChapter(n) → Promise<{CHAPTER, LESSONS}>`: 메모리 → 네트워크(서비스 워커가 저장본을 줌) 순서로 가져온다. 개발 모드(`tools/dev.py`)에서는 지금처럼 `data/lessons/chN.js`를 import한다.
- 학습 길, 설정 「학습 내용」, 진도 계산, 배지·퀘스트는 레슨 목록만 쓴다(장 파일 불필요).
- 레슨을 열 때: `getChapter` → 0.3초 넘게 걸리면 「준비 중」 표시.
- 복습: `review_queue`의 개념이 들어 있는 장만 가져와 문제를 고른다.
- 실패 시: 리아 「이 장은 인터넷이 될 때 한 번 열어 주세요」 + 「다시 시도」, 「학습 길로」 버튼. 진행·저장에는 영향 없음.

## 3. 오프라인 (서비스 워커)

- 설치 단계에서 게임 파일과 **모든 장 파일**을 미리 저장한다. 장 파일 하나라도 실패하면 설치는 계속하고, 그 장은 처음 열 때 받는다.
- 장 파일은 이름에 지문이 있어 바뀌지 않으므로 「저장본 먼저」로 준다. 새 판을 올리면 새 이름이 생기고, 옛 게임 저장본과 함께 지운다.
- 설정 「오프라인 준비 완료」 조건에 「장 파일 전부 저장됨」을 더한다.
