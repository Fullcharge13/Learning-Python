> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 밝은 화면에서 4.5:1에 못 미치는 글자 9곳을 색만 바꿔 고친다.
**Architecture:** CSS 값과 설치 안내 SVG 색 하나만 바꾼다. 화면 구조·글은 그대로.
**Tech Stack:** CSS, Playwright 대비 도구(`tests/contrast.py`).
**Spec:** `docs/specs/2026-11-14-밝은-화면-대비-다듬기-설계.md`

## Global Constraints
- 어두운 화면(`[data-theme="dark"]`) 결과가 바뀌면 안 됨(0건 유지).
- 비활성 단추 배경 `#E9E2D2`는 그대로, 글자만 `#5C574C`.
- 그대로 두는 곳: 배지 그림 속 글자, 경비실 목록 잠긴 줄.

## Review Focus
1. `.tab.locked`에서 opacity를 없앴을 때 잠긴 칸의 아이콘·빨간 점이 안 잠긴 칸과 구별되는지(밝게) → 고친 뒤 대비 도구 화면 `home` 캡처로 확인.
2. `.g-ln` opacity 변경이 일반 줄 번호(은은해야 함)까지 번지지 않는지 → 대비 도구가 일반 줄 번호를 새 실패로 잡지 않고, 선택자가 `.g-line.now`·`.g-now` 안으로만 좁혀졌는지.
