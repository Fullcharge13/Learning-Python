## 실행 방법

처음 한 번은 `npm install`로 개발 도구(CodeMirror 입력창, esbuild 묶음 도구, 시험용 Pyodide)를 받아요.

| 하고 싶은 일 | 명령 | 설명 |
|---|---|---|
| 개발하면서 열어 보기 | `python3 tools/dev.py` | 코드를 묶어 `http://127.0.0.1:8765/dev/`로 열어 줘요 |
| 배포 파일 만들기 | `python3 build.py` | `dist/`에 `index.html`(앱과 레슨 목록) + `lessons/`(장마다 문제 파일) + `manifest.webmanifest` + `sw.js` + 아이콘. **`lessons/` 폴더까지 함께** 이 폴더를 그대로 웹에 올리면 돼요(영어판 `lessons/en/`·`lang/` 포함) (Pyodide 제외 600KB 이하) |
| README 다시 만들기 | `python3 tools/readme_gen.py` | 데이터 표를 바꾼 뒤 실행. `--check`는 어긋남만 검사 |
| 리아 그림 데이터 다시 만들기 | `python3 tools/ria_set2_import.py` | 원본 `art/ria_set2_sheet.svg`(#리아_이미지_세트2)를 고친 뒤 실행 → `data/ria_set2.js` |
| 리아 그림 시트 다시 뽑기 | `python3 tools/ria_sheet.py` | `docs/img/ria-sheet.png`, `ria-hero.png` |
| README 첫머리 화면 캡처 바꾸기 | `python3 tests/flow.py` 뒤 `python3 tools/readme_shots.py` | `docs/img/screen-home.png`, `screen-write.png`, `screen-done.png` |

**시험 (확인 도구)**

| 명령 | 확인하는 것 |
|---|---|
| `npm test` | 규칙 단위 시험: 저장·옛 저장 옮기기, 연속 기록 날짜 계산, XP·바이트, 퀘스트·배지·상점, 채점 비교, 대사, 그림 |
| `python3 -m pytest tests/py -q` | 채점기(`runner.py`)를 일반 Python으로 시험: `input()` 값, 오류 줄 번호, 코드 구조 조건 |
| `python3 tests/content.py --full 17` | 레슨 85개 전체 점검: 정답 코드가 시험을 통과하는지, 시작 코드는 통과하지 않는지, 힌트 4개 등 |
| `python3 tests/content.py --lang en --full 17` | 영어 레슨(`data/lessons/en/`)을 같은 방법으로 점검: 영어 코드 실행 결과 = 정답 |
| `python3 tests/lesson_parity.py` | 영어 레슨이 한국어와 모양이 같은지(id·정답·문제 수), 한글이 남지 않았는지, 모든 장이 영어인지 |
| `python3 tests/i18n_coverage.py` | 영어 화면 문구: 감싸지 않은 한글·빠진 영어·남는 영어·값 자리 수 |
| `python3 tests/grader_browser.py` | 실제 브라우저(Chromium) 안 Pyodide 작업자: 실행, 입력, 3초 시간 초과 뒤 재시작 |
| `python3 tests/build_test.py` | 배포 파일: 한 장인지, 크기 상한, 버전 표시, 오프라인 열기 |
| `python3 tests/flow.py` | 아이폰 17 크기 화면 순회: 넘침·콘솔 오류·터치 크기·첫 레슨 끝까지·옛 저장 |
| `node tests/sim/economy.js` | 가상 학습자 30일 × 12판 바이트 경제 시뮬레이션(중앙값 표) |

시험 중 브라우저를 쓰는 것은 Playwright(브라우저를 자동으로 조작하는 도구)의 Chromium이에요. 사파리(WebKit)로는 시험하지 못해서, 실제 아이폰에서 확인할 목록을 `docs/device-checklist.md`에 따로 두었어요.

## 폴더 구조

```
  src/                      화면·규칙 코드, 리아 교수 그림(SVG), 소리, Pyodide 작업자
  src/py/runner.py          학습자 코드를 실행·채점하는 Python 코드(Pyodide 안에서 돎)
  data/lessons/             1~17장 레슨 표 (ch1.js … ch17.js)
  data/                     개념·대사·퀘스트·배지·의상·오류 설명 표
  build.py                  모든 것을 HTML 한 장(dist/index.html)으로 합치기
  tools/                    개발 서버, README 생성, 그림 시트·아이콘 만들기
  art/                      리아 그림 원본: #리아_이미지_세트2 시트(ria_set2_sheet.svg, 앱이 씀), #리아_이미지_세트1 보관본(ria_set1/, 빌드에 안 들어감)
  tests/                    시험 도구 (unit, py, sim, 브라우저 시험)
  docs/specs/               설계서
  docs/plans/               계획서와 실행 기록(ledger)
  docs/img/                 README용 그림 (스크립트로 뽑음)
  docs/device-checklist.md  실제 아이폰에서 확인할 목록
  README.md LOG.md          설명서(자동 생성)와 개발 일지
```

게임 내용(레슨·퀘스트·배지·의상)은 모두 `data/` 표에 있어요. 표를 고치면 화면 코드는 그대로 두고 내용만 바뀌어요.

## 레슨 85개 + 심화 51개

한 레슨: 학습 목표 → 개념 카드 1~2장 → 터치 문제(객관식·빈칸·순서) → 직접 작성 1문제 → 이해도 확인 → 틀린 문제 다시 풀기 → 완료 요약. 레슨은 차례로 열려요.

**심화**(선택): 장 평가를 통과하면 그 장의 심화 레슨 3개가 한꺼번에 열려요. 건너뛰어도 다음 장은 열리고, 과정 완주와 「레슨 N개 중 M개 완료」에는 들어가지 않아요. 학습 길에서는 장 평가 아래 별 노드로 보여요.

**매일 도전**(v0.9): 홈 맨 위 「오늘의 도전」 카드. 하루 3문제 — 문제 틀 83개에서 이름·숫자를 바꿔 만든 터치 2문제와 끝낸 레슨의 직접 작성 1문제(틀린 개념이 든 레슨을 더 자주). 끝낸 장에서만 나오고, 같은 날 다시 열면 같은 문제예요. 다 풀면 XP 15 · 바이트 10, 「도전 n일째」 연속 7일마다 바이트 +20. 비행기 모드에서도 돼요.

## 경비실 (v0.15~)

텃밭 화면 안의 「경비실」(사이버 보안 배우기). 가상의 해커 크로우가 공격해 오면, 배운 파이썬으로 경비 코드를 짜서 막아요. 빈칸 채우기로 풀거나 코드로 직접 쓸 수 있고, 「실행」하면 크로우의 시도가 하나씩 다시 재생돼요(🛡 막음 / ✅ 들임 / ❌ 뚫림). 처음 해결하면 XP 5. 방어하는 쪽의 글만 있고, 사람·기관은 모두 가상이에요.

기본 사건 45개(3~17장, 장마다 3개). 그 장을 끝내면 그 장의 기본 사건이 열려요. 사건 본문은 장마다 따로 파일(`guard/chN-지문.json`)로 두고 처음 열 때 받아요(첫 파일에는 목록용 색인만).

여기에 「응용 사건」 15개가 더 있어요(장마다 1개). 그 장의 기본 사건 3개를 모두 해결하면 열리고, 풀면 실제 공격 이름·현실 모습·내가 할 일·검색어가 담긴 「사건 파일」 카드가 열려요. 응용 사건은 보안 등급과 「n/45 해결」에 세지 않아요.

## 게임 장치

- **XP**(경험치): 레슨 첫 완료 10 (장 평가 30, 심화 15) + 실수 없음 5 + 힌트 없이 직접 작성 통과 5. 다시 하기는 10 (장 평가 15), 복습 한 판 10.
- **하루 목표와 연속 기록**: 하루 목표 10·20·30 XP(기본 20)를 채운 날마다 +1. 기록 보호권(200바이트, 최대 2개)이 빠진 날을 메워 줘요. 7·30·100일에 축하와 보상.
- **바이트**: 게임 속 돈. 레슨 첫 완료 10 (심화 15) + 실수 없음 5, 퀘스트, 보물상자 10, 연속 7일 50. 의상과 보호권을 사요.

- 사파리는 홈 화면에 추가하지 않은 웹사이트의 저장을 7일 동안 방문이 없으면 지울 수 있어요. 홈 화면에 추가를 안내하고, 브라우저에 저장 보존을 요청하며(`navigator.storage.persist`), 설정에 저장 내보내기·가져오기를 두었어요.
- 서버가 없어 「숨은 시험」의 답도 앱 파일 안에 들어 있어요. 마음먹고 파일을 열어 보면 볼 수 있어요.
- 채점은 출력과 「꼭 쓸 문법」(함수·반복·주석·elif·else 등)을 보지만, 「객체에 이름을 담았는지」처럼 값의 흐름까지는 보지 않아요(15-1, 16-1에 작은 빈틈).
- 설정 맨 아래 「개발자 모드」(v0.11.1, 검수용): 켜면 모든 레슨·심화·매일 도전 범위·텃밭 노드가 열리고, 진행은 학습 기록과 따로 저장돼요(끄면 원래 기록으로). 누구나 켤 수 있어요.
- 심화 채점의 남은 빈틈: SQL 문제는 JOIN·HAVING 낱말이 SQL 글자 안에 있는지만 보고(16-A1~A3), 15-A1은 starter 아래쪽을 지우고 직접 찍으면 통과하며, 14-A2는 다시 읽은 값을 꼭 쓰지 않아도, 13-A1은 정해진 답 표로도 통과해요. 일부러 꾀를 내야 하는 빈틈이라 그대로 두었어요.
- 레슨 중간 진행은 24시간 동안만 이어서 할 수 있어요. 다른 휴대폰이나 브라우저로는 이어지지 않아요.
- PC에서도 열리지만 휴대폰 폭 그대로 가운데에 놓여요.
- 영어판은 원어민 검수를 받지 않았어요. 번역과 파이썬 정확성은 자동 검사와 두 차례 검수로 맞췄지만, 어색한 표현이 남아 있을 수 있어요.
- 영어 휴대폰에서 처음 열기, 영어 홈 화면 앱 이름(Ria & Python), 영어로 비행기 모드 쓰기는 자동 시험으로만 확인했고 실제 기기로는 아직 확인하지 않았어요.
- 아이폰 SE처럼 작은 화면에서는 시작 화면 단추가 아래로 밀려 화면을 내려야 보여요.
- 좁은 화면에서는 텃밭 화면의 제목이 잘려요.
- 설정에서 언어를 바꾸면 화면을 다시 그리면서 스크롤 위치가 위로 튀어요.
- 「홈 화면에 추가」 안내는 아이폰 사파리와 안드로이드 크롬만 있어요(삼성 인터넷 등 다른 브라우저 안내는 없음).
- 안드로이드(갤럭시) 삼성 키보드에서 코드 입력창의 엔터가 안 먹는다는 제보가 있어요. 키보드와 상관없이 쓸 수 있게 기호 줄 맨 앞에 「↵ 줄 바꿈」 단추를 두었고, 처음 주어지는 코드는 정답 줄 수만큼 빈 줄이 미리 있어요(v0.12.2). 입력 방식 자체를 바꾸는 시도는 글자 입력을 망가뜨려 되돌렸어요(v0.12.3). 자동 시험은 Chromium에 갤럭시 화면을 입혀서 하므로 진짜 삼성 키보드의 동작은 실기기로만 확인할 수 있어요.
