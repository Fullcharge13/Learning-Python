# 「파이의 텃밭」 6~9장 확장 설계 (리아와 파이썬! v0.11)

- 작성일: 2026-11-05 · 상태: **확정**(사용자: 범위 A「6~9장」, 설계 ① 뒤 「추천대로 구현까지」)
- 바탕: `docs/specs/2026-11-05-파이의-텃밭-설계.md`(v0.10), 판정 C59~C64

## 1. 새 노드와 명령

| 장 | 노드 | 코드 | 비고 |
|---|---|---|---|
| 6 | 값 넣어 말하기 `sayval{text,var}` | `print("당근 " + str(count) + "개")`(앞 글자·값·뒤 글자) | 앞·뒤 글자 각 10자, 값은 정해진 값 이름 또는 7·9장 변수 |
| 7 | 목록에서 하나씩 `foreach{list,var}` | `for crop in ["당근", "감자", "당근"]:` | 목록 종류: 작물 목록(당근·감자, 1~6개) / 방향 목록(위·아래·왼쪽·오른쪽, 1~6개). 변수 이름은 작물이면 `crop`, 방향이면 `way`(겹치면 `crop2`·`way2`) |
| 7 | (값 고르기 확장) | `plant(crop)`, `move(way)` | 목록 노드 **안쪽**의 심기·이동 노드는 값으로 그 변수를 고를 수 있음 |
| 8 | (조건 추가) 창고 보기 | `store()["당근"] < 10` | 작물·비교(<,>,==)·숫자 0~99 |
| 9 | 위치 알기 `where{}` | `x, y = where()` | 이 노드 뒤(같은 층·바깥 층 규칙, C64)에서 `x`·`y`를 값 비교 조건과 값 넣어 말하기에 쓸 수 있음 |

새 명령(시간 0, 살펴보기 수에 포함 — C60의 2000번 한도):
- `store()` → 창고 사본 `{"당근": n, "감자": n}`(학습자가 바꿔도 실제 창고 그대로).
- `where()` → `(x, y)` 튜플.

## 2. 주문 7개 추가(모두 22개)

| 장 | 주문(제목) | 목표 |
|---|---|---|
| 6 | 수확 보고 | use sayval |
| 7 | 섞어 심기 | use `loopvar:act`(목록 값을 심기·이동에 씀, C67) |
| 7 | 한 바퀴 순찰 | run_harvest n 3, kind foreach(방향 목록으로 움직이며 거두기) |
| 8 | 모자란 것만 | use store 조건(창고 확인 조건이 든 만약/동안) |
| 8 | 감자 장부 | deliver 감자 5 |
| 9 | 줄 끝에서 내려가기 | use `cond:pos`(위치 조건, C67) |
| 9 | 지그재그 수확 | run_harvest n 9, kind where |

- 판정 `use`에 「조건 종류」도 셀 수 있게 `kindsUsed`가 `cond:store`·`cond:pos` 같은 표지를 함께 돌려준다.
- 주문마다 정답 노드 + 시작 상태, `tests/garden_orders.py`로 실제 엔진 검사(지금과 같음).

## 3. 하루 퀘스트 연결

- 퀘스트 `q_garden`(「텃밭 주문 1개 해내기」, 사건 `garden_order`, 목표 1, 보상 5바이트).
- **텃밭이 열린 학습자에게만** 뽑힐 수 있다(1장 평가 통과). 열리지 않았으면 후보에서 뺀다.
- 경제 시뮬레이션: 텃밭 학습자 줄을 추가해 첫 의상 날짜(목표 3~4일)가 그대로인지 확인.

## 4. 텃밭 오류 설명

텃밭 화면의 오류 설명은 텃밭 전용 문장을 먼저 찾고, 없으면 기존 설명:

| 상황 | 설명 |
|---|---|
| ValueError 방향 | 「move 안에는 "위"·"아래"·"왼쪽"·"오른쪽" 중 하나를 따옴표와 함께 넣어요」 |
| ValueError 작물 | 「plant 안에는 "당근"이나 "감자"를 넣어요」 |
| TypeError (`plant(1)`, `move()` 등) | 「명령 괄호 안의 값 개수·모양을 확인해요. 예: move("오른쪽")」 |
| NameError 명령 오타 | 「텃밭 명령은 move·plant·harvest·can_harvest·what_here·store·where예요. 철자를 확인해요」(가까운 이름이 있으면 「혹시 ○○?」) |
| KeyError (`store()["수박"]`) | 「창고에는 "당근"·"감자"만 있어요」 |

## 5. 시험

pytest(`store`·`where`·사본·살펴보기 수), 노드 단위(새 노드 코드·검사·목록 변수 범위·위치 변수 범위), 주문 22/22, 퀘스트 단위(텃밭 잠김이면 안 뽑힘), 경제 시뮬레이션, 화면 순회(새 고르기 창·아이폰 17), 텃밭 오류 설명 단위.
