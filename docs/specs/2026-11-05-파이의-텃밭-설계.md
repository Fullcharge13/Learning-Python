# 「파이의 텃밭」 설계 (리아와 파이썬! v0.10)

- 작성일: 2026-11-05 · 상태: **확정**(사용자: 설계 ①·② 확인, 나머지는 「추천하는 방식으로 구현까지 승인」)
- 참고작: 「농부는 대체되었다」(The Farmer Was Replaced, Timon Herzog, Steam 2060160) — 코드로 드론을 움직여 농장을 자동화하고 자원으로 기술을 여는 구조만 참고한다. 이름·그림·문구는 쓰지 않는다.
- 조작 참고: n8n(노드를 이어 흐름을 만드는 자동화 도구) — 「상자를 이어 흐름을 만든다」는 생각만 가져온다.

## 0. 사용자가 정한 것

| 질문 | 결정 |
|---|---|
| 앱 안 자리 | **배운 것을 써먹는 놀이터**: 장을 끝낼 때마다 그 장에서 배운 것이 새 노드로 열림 |
| 노드와 코드 | **노드를 이으면 진짜 파이썬 코드가 함께 만들어짐**, 익숙해지면 코드로 직접 쓰기 |
| 기본 흐름 | **내 농장 + 주문 게시판**: 농장은 계속 자라고 리아 교수의 주문이 할 일을 알려 줌 |
| 세계·캐릭터 | **리아 교수의 학교 텃밭 + 작은 뱀 「파이」** (앱에 이미 있는 뱀 친구) |
| 화면 배치 | **위에서 아래로 쌓는 세로 흐름**, 반복·조건 안의 노드는 들여쓰기 |
| 보상 | **작물은 게임 안에서만**, 주문을 해내면 XP 조금, 바이트는 주지 않음 |
| 만드는 방식 | **진짜 파이썬으로 실행 → 기록을 재생** |

## 1. 전체 그림과 첫 판 범위

- 홈 화면에 「파이의 텃밭」 입구. **1장 평가(1-5)를 통과하면 열림**. 그 전에는 자물쇠와 「1장을 끝내면 열려요」.
- 텃밭 화면: 위 텃밭(격자 + 파이) / 가운데 노드 흐름 / 아래 파이썬 코드 미리보기(접기).
- 노드는 **장 평가를 통과한 장**의 것만 쓸 수 있다(심화 해금과 같은 기준).

| 장 | 노드 | 만들어지는 코드 |
|---|---|---|
| 1 | 이동 · 수확 · 심기 · 말하기 | `move("오른쪽")` · `harvest()` · `plant("당근")` · `print("…")` |
| 2 | 값 기억하기 · 값 더하기 | `count = 0` · `count = count + 1` |
| 3 | 만약 · 아니면 | `if can_harvest():` · `else:` |
| 4 | 내 노드 만들기 · 내 노드 부르기 | `def go_row():` · `go_row()` |
| 5 | 반복 n번 · ~하는 동안 | `for i in range(3):` · `while count < 9:` |

- 첫 판 넣음: 텃밭 3×3 시작, 작물 당근·감자, 주문 15개, 성장 4가지(밭 4×4, 밭 5×5, 감자 씨앗, 비료), 노드 모드 + 코드 모드.
- 첫 판 뺌: 6장 이후 노드, 파이 여러 마리, 날씨·병충해, 하루 퀘스트 연결(다음 판 후보).

## 2. 실행 방식

1. 노드 → 파이썬 코드(코드 모드면 학습자 코드 그대로).
2. 기존 채점 엔진 `run()`에 `farm=<텃밭 상태>`를 넘겨 실행. 실행마다 새 `farm` 모듈을 `sys.modules`에 넣는다(`chart`와 같은 방식). 학습자 코드는 `from farm import *` 없이도 명령을 쓸 수 있게 **명령 이름을 실행 전역에 미리 넣는다**(레슨 코드처럼 짧게).
3. 게임 규칙은 **`farm` 모듈(파이썬) 한 곳**에만 있다. 명령마다 상태를 바꾸고 사건을 기록한다.
4. 결과 `result.farm = { events: [...], state: {...}, stopped: null | "tired" }`. 화면은 events를 재생하고(1배·2배·건너뛰기), 재생 중 지금 줄의 노드에 불을 켠다.
5. 끝난 상태와 창고를 저장한다. 오류가 나면 오류 직전까지의 상태를 쓰고, 오류 줄의 노드를 빨갛게 표시하며 기존 한국어 오류 안내를 보여 준다.

### 2-1. 명령

| 명령 | 하는 일 | 시간 |
|---|---|---|
| `move(방향)` | `"위"`·`"아래"`·`"왼쪽"`·`"오른쪽"` 한 칸, 끝에 닿으면 반대편으로(감싸기) | 1 |
| `plant(작물)` | 빈 칸에 `"당근"`/`"감자"` 심기. 칸이 차 있거나 씨앗이 없으면 아무 일 없음(사건 `plant_fail`) | 1 |
| `harvest()` | 다 자랐으면 거두어 창고에 +1, 칸은 빈칸. 덜 자랐으면 작물이 사라짐(사건 `harvest_young`) | 1 |
| `can_harvest()` | 지금 칸이 다 자란 작물이면 `True` | 0 |
| `what_here()` | `"당근"`·`"감자"`·`"빈칸"` | 0 |
| `print(...)` | 파이 머리 위 말풍선(사건 `say`, 출력도 그대로) | 0 |

- 잘못된 값(`move("앞")`, `plant("수박")`)은 `ValueError`와 한국어 메시지(「방향은 위·아래·왼쪽·오른쪽 중 하나예요」).
- 성장: 당근 8, 감자 12(비료 성장 뒤 6·9). 시간은 행동 하나에 1씩 흐르고, 실행 사이에도 이어진다(`state.clock`). 심은 칸은 `planted_at`을 기억한다.
- 기다리다 지침(C60): 살펴보기(`can_harvest`·`what_here`)는 한 실행에 2000번까지, 넘으면 `stopped:"waited"`.
- 결과 대조(C62): 앱이 실행 결과를 사건 기록과 대조해 맞지 않으면 버린다. 말하기 사건은 100개까지만 기록(행동 사건은 빠짐없이).
- 파이가 지침: 한 실행에 행동(시간 1짜리) **500번**까지. 501번째 행동에서 실행을 멈추고 `stopped:"tired"`, 그때까지 한 일은 남는다. `while True:`도 안전.
- 감자는 「감자 씨앗」 성장을 산 뒤에만 심을 수 있다(그 전에는 `plant_fail`, 말풍선 「감자 씨앗이 아직 없어요」).

## 3. 노드 편집기와 코드

- 프로그램 = 노드 목록(트리). 노드 `{ id, kind, args, body? , orelse? }`. `body`가 있는 노드(반복·조건·내 노드 만들기)는 안에 노드를 담는다.
- 노드 종류(첫 판): `move{dir}` `harvest` `plant{crop}` `say{text}` `setvar{name,value}` `addvar{name,value}` `if{cond}`(+`orelse`) `def{name}` `call{name}` `repeat{n}` `while{cond}`.
- 조건(`cond`)은 고르는 목록: `can_harvest()`, `not can_harvest()`, `what_here() == "빈칸"`, `what_here() == "당근"`, `what_here() == "감자"`, 그리고 2장을 끝냈으면 `<값> < 숫자`(값 이름과 숫자를 고름).
- 값 이름은 미리 정한 목록(`count`, `n`, `total`)에서 고른다. 내 노드 이름은 미리 정한 목록(`go_row`, `plant_row`, `harvest_row`, `tend`)에서 고른다 — 입력 실수 없이 휴대폰에서 고르기만.
- 숫자는 −/+ 단추(반복 1~25, 값 기억하기 0~99, 값 더하기 1~99 — C64). 말하기 글자는 20자까지.
- 검사(구현 뒤 판정): 내 노드 안에서 값 바꾸기 금지(C59), 끝나지 않는 「~하는 동안」 금지(C64), 값은 같은 층·바깥 층(만약·동안 밖)에서 정해야 함.
- 한도: 노드 60개, 안쪽 깊이 4.
- **노드 → 코드는 한 방향**: 코드 생성기가 코드와 「줄 → 노드 id」 표를 함께 만든다. 「코드로 쓰기」를 누르면 지금 코드를 편집기에 복사해 코드 모드로. 코드 모드에서 「노드로 돌아가기」는 코드를 고치지 않았을 때만 바로, 고쳤으면 「코드에서 고친 것은 사라져요」 확인 뒤.
- 노드 추가는 「＋」 → 열린 노드만 보이는 고르기 창(잠긴 노드는 「n장을 끝내면 열려요」로 흐리게). 순서 바꾸기는 위·아래 단추(끌기는 다음 판), 지우기는 노드 메뉴.

## 4. 주문·성장·저장·보상

- **주문** 15개(데이터 표 `data/garden.js`의 `ORDERS`). 한 번에 하나가 게시판에 걸리고, 해내면 다음 주문. 주문마다 `need`(필요한 장), 목표, 리아 교수 한마디, 보상 XP.
  - 목표 종류: `deliver{crop,n}`(창고에서 n개 보내기 — 단추), `run_harvest{crop?,n,max_actions?}`(한 번 실행에 n개 이상 거두기, 행동 수 제한 선택), `use{kind}`(그 노드를 쓴 실행이 오류 없이 끝남), `grid{size}`(밭 넓히기 성장을 삼).
  - 장이 안 열린 주문은 「n장을 끝내면 이어져요」로 기다림(게시판이 막히지 않게 다음으로 넘기지 않음 — 주문 차례는 장 순서와 맞춤).
  - 보상: 주문마다 **XP 5**(15개 합 75). 바이트 없음. XP는 기존 하루 목표·연속 기록에 들어간다.
- **성장**(창고 작물로 삼): 밭 4×4(당근 20), 밭 5×5(당근 40 + 감자 15), 감자 씨앗(당근 10), 비료(감자 20). 밭을 넓혀도 기존 작물은 제자리, 새 칸은 빈칸.
- **저장** `save.garden`(saveVer 그대로 2, 없으면 기본값으로 채움):
  `{ v:1, size:3, cells:[{crop,planted_at}|null…], pie:{x,y}, clock:0, store:{당근:0,감자:0}, upgrades:[], order:{idx:0, done:[]}, program:[노드…], code:"", mode:"nodes"|"code", runs:0 }`
- 시작 프로그램: `move("오른쪽")`, `harvest()` 두 노드(빈 화면 막기). 시작 밭: 3×3에 당근 3개(일부 다 자람)가 심겨 있음.

## 5. 그림·소리

- 파이: 앱에 있는 `snake()` 그림을 위에서 본 텃밭 크기로 다시 쓴다(새 캐릭터 없음). 작물·흙은 SVG 코드로 그린다(이미지 파일 없음).
- 소리: 기존 `sound.js`의 짧은 음을 다시 씀(수확·주문 완료).
- 줄이기 설정(움직임 줄이기)에서는 재생을 건너뛰고 결과만 보여 준다.
