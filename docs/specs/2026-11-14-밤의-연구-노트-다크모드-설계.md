# 밤의 연구 노트 (다크 모드) — 설계서 (v0.19.0 후보)

날짜: 2026-11-14 · 브랜치: `feature/tutorial-dark` (`feature/guard-room` f4fc6bb + 20d9888 튜토리얼 입력칸 글자색 고침)

## 1. 왜 하나

- 사용자: 휴대폰을 다크 모드로 바꿔도 앱이 밝은 그대로라 별로다. 다크 모드 켜기·끄기와 시스템 설정 따라가기를 원함.
- 지금: `src/style.css`의 `:root`에 `color-scheme: light` 고정, 색 이름표 27개(`--paper`, `--card`, `--ink` …), 직접 적은 색 약 70곳(`#fff` 15곳 포함), `rgba(` 24곳. `src/index.html`의 `<meta name="theme-color" content="#FBF6EA">`. 코드 편집기는 CodeMirror `defaultHighlightStyle`(밝은 바탕용).
- 사용자 선택: **A 「밤의 연구 노트」** — 크림 모눈종이를 짙은 남색 종이로, 청록·노랑·산호 강조색은 유지, 그림은 그대로. 나머지는 설계자 제안대로(사용자 승인).

## 2. 목표 / 하지 않을 것 / 실패로 볼 것

**목표**
1. 설정 「화면」: 시스템 따라가기(기본) · 밝게 · 어둡게. 시스템 따라가기는 앱이 켜진 채 휴대폰 설정이 바뀌어도 바로 따라감.
2. 앱을 처음 그리는 순간부터 고른 색(밝게 번쩍임 없음).
3. 어두운 화면의 모든 글자·바탕 대비 **≥ 4.5:1**(큰 글씨·아이콘 단추 테두리는 ≥ 3:1), 자동 시험.
4. 밝은 화면은 지금과 픽셀 단위로 같음(시각 회귀 없음).

**하지 않을 것**
- 리아·크로우·파이(뱀)·배지·의상 그림, 텃밭 밭·작물 그림의 어두운 버전. 레슨·기능 변경. `saveVer` 변경. 학습 기록 저장(`ria-python.save`)에 화면 설정 넣기.

**실패로 볼 것**
- 어두운 화면에서 안 보이는 글자·단추(대비 미달), 흰 입력칸에 흰 글자 같은 상속 문제.
- 앱을 열 때 밝게 한 번 번쩍임.
- 밝은 화면이 바뀜.
- 첫 파일 600KB 한도 초과, v0.18.0보다 첫 화면이 10% 넘게 느려짐.

## 3. 설계

### 3-1. 저장과 적용

- 화면 설정은 **기기 단위**: `localStorage["ria-python.theme"]` = `"system"`(없을 때 기본) | `"light"` | `"dark"`. 학습 기록과 따로라 개발자 모드로 바꿔도 그대로, 기록 가져오기에도 안 따라감.
- `<html data-theme="light|dark">`로 적용. `src/index.html` 머리의 기존 「여는 중」 스크립트 옆에 같은 방식의 아주 작은 스크립트를 두어 **CSS보다 먼저** `data-theme`를 정한다(설정 읽기 → `system`이면 `matchMedia("(prefers-color-scheme: dark)")`). localStorage를 못 읽으면 시스템을 따름.
- 앱의 `src/theme.js`: `getTheme()`, `setTheme(value)`, `resolvedTheme()`, `watchSystem(cb)` — `system`일 때 `matchMedia` 변화에 `data-theme`·`theme-color`를 바꿈.
- `<meta name="theme-color">`를 고른 색의 바탕색으로 바꿈(밝게 `#FBF6EA`, 어둡게 아래 `--paper`). `color-scheme`도 `light`/`dark`로 맞춰 스크롤 막대·기본 입력 모양이 따라가게.

### 3-2. 색 (밤의 연구 노트)

- `:root`(밝게)는 지금 값 그대로. `[data-theme="dark"]`에서 같은 이름표를 다시 정의한다. 시작 값(만드는 사람이 대비 시험으로 다듬음):

| 이름표 | 밝게 | 어둡게(시작 값) |
|---|---|---|
| `--paper` | #FBF6EA | #141C2B |
| `--paper-2` | #F2E9D5 | #1B2538 |
| `--card` | #FFFDF8 | #1E2940 |
| `--line` | #E2D6BD | #34425E |
| `--ink` | #22304A | #F1EBDD |
| `--ink-2` | #555F72 | #B7BFCD |
| `--teal` / `--teal-ink` / `--teal-deep` / `--teal-soft` | 그대로 | 밝기 올린 청록 / 바탕 위에서 읽히는 청록 / 단추용 / 짙은 청록 바탕 |
| `--sun*`, `--coral*` | 그대로 | `*-soft`는 어두운 색조, `*-ink`는 밝은 색조 |
| `--navy`(코드 상자) | #1F2B3D | #0E1522 |

- 모눈 무늬(`body` 배경 `rgba(34,48,74,.045)`)는 어둡게에서 밝은 선(`rgba(241,235,221,.04)` 근처).
- **직접 적은 색**(`#fff`, `#F4EEDD`, `rgba(...)` 등)은 이름표로 바꾸거나 어둡게용 값을 따로 둔다. 그림(SVG 데이터 `data/ria_set2.js`, `data/crow.js`, 텃밭 작물·밭 그림)의 색은 손대지 않는다. 텃밭 화면의 **판·틀·글자**(그림이 아닌 부분)는 이름표를 따른다.
- 코드 편집기: 어둡게일 때 어두운 바탕용 문법 색(`HighlightStyle` 하나 추가, 편집기 묶음 안). 줄 번호·커서·선택 색도.
- 그래프(`src/chart.js`)·진행 막대·시트·팝업·토스트·아래 메뉴·경비실 판정 칸·텃밭 노드 편집기 포함.

### 3-3. 설정 화면

- 「화면」 줄: 라벨 「화면」 + 설명 「밤에는 어두운 화면이 눈이 편해요」, 세 단추(라디오 묶음): 「시스템 따라가기」·「밝게」·「어둡게」(영어 System / Light / Dark). 누르면 즉시 바뀜.
- 한·영 문구는 `t```와 `i18n/en/ui.*.json`.

### 3-4. 크기

- CSS 이름표 다시 정의 + 작은 스크립트 + 설정 줄: 예상 3~6KB(첫 파일). 문법 색은 편집기 묶음(420KB 한도 안).

## 4. 시험

- 단위: `theme.js` — 저장 값 없음 → system, 잘못된 값 → system, `setTheme` 저장, `resolvedTheme`이 `matchMedia` 따름.
- 대비 자동 시험(`tests/flow.py`, 어둡게): 주요 화면(인사, 튜토리얼 4장, 홈, 레슨 카드·고르기·빈칸·코드 쓰기·오류 카드, 완료, 배지, 의상실, 설정, 텃밭(1장 통과 저장), 경비실 빈칸·직접 쓰기·판정 칸, 시트·팝업)에서 **보이는 글자 요소 전부**의 글자색과 실제 바탕색(조상 중 첫 불투명 배경) 대비를 계산 → 4.5:1 미만 목록이 비어야 함(큰 글씨 24px 이상·굵은 19px 이상은 3:1). 같은 시험을 밝게에서도 돌려 기존 화면의 숨은 문제를 찾되, 밝게의 기존 미달은 목록으로 보고만(고칠지는 판정으로).
- 번쩍임 없음: 어둡게 저장으로 열 때 첫 그림(첫 `requestAnimationFrame`) 시점의 `html[data-theme]`가 `dark`, `body` 배경이 어두운 색.
- 시스템 따라가기: Playwright `color_scheme` 바꿈(`page.emulate_media`) → 앱 켜진 채 `data-theme`가 따라 바뀜. 밝게·어둡게 고정이면 안 따라감.
- 설정: 세 단추, 누르면 즉시 바뀌고 새로 고침 뒤 유지, 개발자 모드 바꿔도 유지. 영어판 문구.
- 밝은 화면 회귀: 주요 화면 몇 곳의 밝게 스크린숏이 v0.18.0과 픽셀 차이 없음(또는 계산된 색 값 비교).
- 편집기: 어둡게에서 코드 글자·키워드 색 대비 ≥ 4.5:1.
- 기존 전체 묶음 통과, 첫 화면 시간(느린 3G)이 v0.18.0(1.13s, 1.24s)보다 10% 넘게 나빠지지 않음.

### 3-5. 정해 둔 것 (설계자 판단 — 사용자 검토용)

- **텃밭 그림 안의 말풍선·글자**(`src/garden/view.js`의 `COL.card`·`COL.ink`·`COL.gray`·`#fff` 등)는 「글자」로 보고 이름표를 따른다(SVG 속성에 `var(--card)` 같은 CSS 변수). 밝게에서는 같은 값이라 픽셀이 그대로다. 리아·크로우·파이의 몸·윤곽선은 그림이라 그대로(밤 바탕 위 짙은 윤곽선은 실기기 확인 항목).
- **편집기**: 편집기 묶음은 앱 모듈을 가져오지 않으므로 `<html data-theme>`를 직접 읽고 그 속성 변화를 지켜본다. 문법 색은 CodeMirror `Compartment`로 끼워, 열려 있는 편집기도 테마가 바뀌면 바로 따라 바뀐다.
- **「번쩍임 없음」의 범위**: 페이지의 첫 그림까지(머리 스크립트 + `body` 바탕). 홈 화면 앱의 시작 그림(매니페스트 `background_color`·`theme_color`)과 iOS 상단 상태 표시줄 모양(`apple-mobile-web-app-status-bar-style`)은 운영체제가 정적으로 쓰므로 **알려진 한계**로 두고 실기기 확인 항목에 넣는다. 매니페스트를 두 벌로 만들지 않는다.
- **밝게의 대비 미달**: 밝게는 지금 그대로 둔다(픽셀 회귀 없음 우선). 밝게 대비 시험은 미달 목록을 보고만 하고 실패시키지 않는다. 어둡게에서만 필요한 고침은 `[data-theme="dark"]` 아래에서만.
- **설정 자리**: 「소리·하루 목표·이름」 묶음 다음, 「저장」 묶음 앞에 「화면」 묶음 하나.
