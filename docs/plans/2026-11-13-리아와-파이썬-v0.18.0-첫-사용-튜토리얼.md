# 첫 사용 튜토리얼 (v0.18.0) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 처음 온 사람이 「시작하기」 뒤 카드 4장을 보고 4장째에서 첫 `print`를 직접 실행하게 하고, 건너뛰기·설정 다시 보기를 넣는다.

**Architecture:** 저장에 `tutorial` 칸(`null|"done"|"skipped"`)을 `src/save.js` 정리 규칙으로 더하고, 순수 함수 모듈 `src/tutorial.js`(입력 → 파이썬 문자열, 띄울지 판단)를 만든다. 새 화면 `src/ui/tutorial.js`가 카드와 실행을 맡고, `splash.js`·`settings.js`·`app.js`는 연결만 한다.

**Tech Stack:** 기존 그대로. 새 의존성 없음.

**Spec:** `docs/specs/2026-11-13-첫-사용-튜토리얼-설계.md`

## Global Constraints

- 작업 브랜치 로컬 `feature/first-run-tutorial`(9d3deb4에서). **푸시·합치기 금지**.
- `saveVer` 2 그대로. XP·바이트 지급 없음. 레슨·홈·텃밭·경비실 동작 변경 없음.
- 튜토리얼은 코드 편집기 묶음(`js/editor-*.js`)을 쓰지 않는다. 첫 파일 600KB 한도(지금 470,704B).
- 화면 문구는 `t```, 영어는 새 `i18n/en/ui.tutorial.json`(기존 `ui.*.json` 규칙·`i18n_coverage` 통과). 리아는 존댓말. 문구 원문은 설계서 §3-2 표 그대로.
- 입력칸 최대 30자, 기본값 「안녕하세요!」(영어 「Hello!」). 결과는 `textContent`로만.
- `README.md`는 `tools/readme_gen.py`로만. 판정은 `docs/plans/ledger.md`「v0.18.0」 표 T-C1….
