# 「리아와 파이썬!」 v0.10 계획서 — 파이의 텃밭

**목표**: 1장 평가 뒤 열리는 프로그래밍 게임 「파이의 텃밭」(노드 → 진짜 파이썬 → 기록 재생)을 앱에 넣는다.
**설계서**: `docs/specs/2026-11-05-파이의-텃밭-설계.md`(확정)
**구조**: 규칙은 `runner.py`의 `farm` 모듈 한 곳, 노드·코드 생성·상태·주문은 `src/garden/` 순수 함수(Node 단위 시험), 화면은 `src/ui/garden.js`.
**전역 제약**: Pyodide 314.0.7, 외부 라이브러리 없음, 이미지 파일 없음(SVG 코드), 아이폰 17(402px) 기준·터치 44px, saveVer 2 유지(없으면 기본값), 코드 폭 38칸 아님(게임 코드는 레슨 점검기 대상 아님), 남의 그림 금지.
**검토 중점**: ① 실행 사이 상태가 이어지고 같은 코드는 같은 결과. ② 무한 반복·500번 지침에서 앱이 멈추지 않음. ③ 잠긴 장의 노드가 코드 모드로도 우회되지 않아야 하나? → 코드 모드는 자유(배운 사람의 놀이터), 주문 `use` 판정은 노드 모드 기준. ④ 주문마다 그 장까지 열린 노드만으로 풀림(`tests/garden_orders.py`). ⑤ 옛 저장(garden 없음)으로 시작해도 홈·텃밭이 열림.

## 인터페이스

```
# T1 runner.py
run(code, stdin=None, require=None, files=None, server=None, farm=None)
  farm: { size, cells:[{crop,planted_at}|None]*size², pie:{x,y}, clock, store:{당근,감자}, upgrades:[...] }
  → result["farm"] = { events:[{t,line,...}], state:<같은 모양>, stopped: None|"tired", actions:int }
  events t: move{dir,x,y} plant{crop,x,y} plant_fail{reason,x,y} harvest{crop,x,y} harvest_young{crop,x,y} say{text}
  farm=None이면 result에 "farm" 없음(기존 동작 그대로)
# T1 pyrun.js / worker.js
py.run(code, "", [], { farm })  → result.farm 전달
# T2 src/garden/nodes.js
NODES: { kind: { chapter, label, body:bool, orelse?:bool, args:{...} } }
unlockedKinds(passedChapters:Set<number>) → Set<kind>
codegen(program) → { code, lineMap:{ [line]: nodeId }, errors:[{nodeId,msg}] }
validate(program, unlocked) → errors[]
newNode(kind, idGen) / insert / move / remove (불변 갱신)
# T3 src/garden/state.js, data/garden.js
newGarden() · fillGarden(save) · runInput(garden) → farm 입력
applyRun(garden, result, {kindsUsed, mode}) → { garden, orderDone?:order }
canBuy(garden, id) · buy(garden, id) · deliver(garden) · currentOrder(garden, passedChapters)
ORDERS[{id, need, title, text, goal, xp:5, solution:[노드]}] · UPGRADES · CROPS
```
