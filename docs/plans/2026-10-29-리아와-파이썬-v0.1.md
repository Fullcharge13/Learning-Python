# 「리아와 파이썬!」 v0.1 계획서

**목표**: 아이폰 17 브라우저에서 리아 교수와 Python 1~3장(레슨 15개)을 터치 문제와 직접 작성으로 배우고, 연속 기록·XP·퀘스트·배지·바이트·의상이 동작하는 HTML 한 장짜리 웹앱을 만든다.

**구조**: 게임 규칙(저장, 진도, 퀘스트, 채점 비교)은 화면과 분리된 순수 함수 모듈로 만들어 Node에서 시험한다. 레슨·대사·퀘스트·배지·의상은 `data/` 표로 두고 화면 코드는 읽기만 한다. Python 실행은 Web Worker 안의 Pyodide가 맡고, `build.py`가 모든 것을 `dist/index.html` 한 장으로 합친다.

**기술**: 일반 JavaScript(ES2022 모듈) · CodeMirror 6(esbuild로 한 파일로 묶어 HTML에 포함) · Pyodide 314.0.7(배포판은 jsDelivr 고정 주소, 시험은 npm 패키지) · Node 22 내장 시험기(`node --test`) · Python 3 + Playwright(Chromium) · Web Audio · SVG.

**설계서**: `docs/specs/2026-10-29-리아와-파이썬-설계.md`

**전역 제약** (설계서에서 그대로 옮김)
- 배포물은 `dist/index.html` 한 장 + `manifest.webmanifest` + `sw.js`. Pyodide 제외 700KB 이하(C28).
- `SAVE_KEY = "ria-python.save"`, `saveVer = 1`. 학습자 상태 이름: `current_chapter`, `current_lesson`, `completed_lessons`, `submission_logs`(최근 50개), `grading_results`, `weak_concepts`, `review_queue`, `last_active_at`. 게임 상태: `xp`, `bytes`, `streak`, `freezes`, `quests`, `badges`, `outfits`, `outfit`, `settings`.
- 실행 제한 3초. 입력칸 글자 16px 이상, 터치 영역 44pt 이상, 안전 영역(`env(safe-area-inset-*)`) 준수.
- 설명은 한국어로 쓰고, Python 코드·키워드·오류 원문은 영어 그대로 둔다. 리아 교수는 존댓말 「~해요」체를 쓰고, 관능적 표현은 쓰지 않는다.
- 이미지 파일 없이 그림은 코드(SVG)로 그린다.
- 커밋·푸시는 사용자가 「커밋해」라고 할 때만 한다. 작성자는 `Claude <noreply@anthropic.com>`이다.

**검토 중점** (테스트가 놓치기 쉬운 순서, 각 항목을 맡은 시험)
1. 연속 기록 날짜 경계: 자정 직전·직후, 이틀 이상 빠짐, 보호권 부족 → 작업 2 `streak.test.js`
2. 시간 초과 뒤 작업자 재시작: 무한 반복 다음 실행이 정상인지 → 작업 5 `grader_browser.py::test_timeout_then_ok`
3. `input()` 값 부족·초과 → 작업 4 `grade.test.js::stdin`, 작업 5 `test_input_short`
4. 깨진 저장·옛 저장으로 시작 → 작업 1 `save.test.js::broken`, `::migrate`
5. 휴대폰 화면 넘침·키보드에 가려지는 「실행」 버튼 → 작업 11 `flow.py::test_no_overflow`, `::test_run_button_visible_with_keyboard` (키보드는 흉내만 가능 → 실기기 목록에 다시 올림)

**설계서와 다른 점 (판정 기록)**
- 설계서 10장은 화면 시험을 WebKit(사파리 엔진)으로 하라고 했다. 이 작업 환경에는 WebKit이 설치되어 있지 않고, Playwright를 새로 설치하면 안 된다. **판정**: Playwright의 `iPhone 17` 기기 설정(402×681, 배율 3, 터치)을 Chromium에 적용해 시험한다. 사파리 고유 동작(저장 7일 규칙, 홈 화면 설치, 실제 키보드)은 실기기 확인 목록(작업 13)에 넣는다. 설계서 10장도 이에 맞춰 고친다.
