# 실행 기록 (ledger) — 리아와 파이썬! v0.1

계획서: `docs/plans/2026-10-29-리아와-파이썬-v0.1.md` · 설계서: `docs/specs/2026-10-29-리아와-파이썬-설계.md`
실행 방식: 작업마다 새 일꾼 + 작업별 2단계 검토(설계 일치 → 코드 품질). worktree 없이 새 저장소에서 작업(사용자 선택 「가」).

## 기준선
- 2026-10-29 작업 0: `npm test` → pass 1, fail 0. Node 22.23.4, Python 3.13.18, pytest 9.1.1, Chromium 153(Playwright). WebKit 없음.
- 설치: esbuild 0.28.2, codemirror 6.0.2, @codemirror/lang-python 6.2.1, pyodide 314.0.7
