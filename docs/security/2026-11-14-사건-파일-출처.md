## G46 · 3장 · 인증 알림 폭탄

- attack: `MFA 피로 공격` · alias: `MFA fatigue`
- real (ko): 비밀번호를 손에 넣은 공격자가 로그인 승인 알림을 계속 보내, 귀찮거나 헷갈린 사용자가 한 번 「승인」을 누르게 만들어요.
- real (en): An attacker who already has the password keeps sending login approval prompts until a tired or confused user taps "Approve" once.
- todo (ko): 내가 로그인하지 않았을 때 온 승인 알림은 누르지 말고, 비밀번호를 바꿔요.
- todo (en): Never approve a sign-in prompt you didn't start, and change your password.
- search (ko): `MFA 피로 공격`, `푸시 폭탄` · (en): `MFA fatigue attack`, `push bombing`
- 출처: CISA·FBI 공동 권고 AA23-320A(Scattered Spider: 반복 MFA 알림) — https://www.cisa.gov/news-events/cybersecurity-advisories/aa23-320a ; MFA 피로 공격 용어(itwiki) — https://itwiki.kr/w/MFA_피로_공격

## G47 · 4장 · 기관 사칭

- attack: `기관 사칭형 보이스피싱` · alias: `government impersonation scam`
- real (ko): 검찰·경찰·금융감독원 직원인 척 「범죄에 연루됐다」고 겁을 준 뒤, 결백을 밝히려면 돈을 옮기라고 요구해요.
- real (en): Scammers pose as prosecutors, police, or financial regulators, scare you by saying you are "involved in a crime," then tell you to move money to prove you are innocent.
- todo (ko): 수사기관은 전화나 메신저로 돈을 옮기라고 하지 않아요. 일단 끊고 기관 대표번호나 112로 확인해요.
- todo (en): Real investigators never ask you to move money by phone or messenger. Hang up and call the agency's official number yourself.
- search (ko): `기관 사칭 보이스피싱`, `안전계좌 사기` · (en): `government impersonation scam`, `vishing`
- 출처: 경찰청 국가수사본부 당부(수사기관은 원격제어 앱 설치·송금 요구 안 함, 대표번호·112로 확인) — 전북일보 2024-07-21 보도 https://www.jjan.kr/articleAmp/20240721580090 ; 토스뱅크 안내 「수사기관은 어떠한 경우에도 안전계좌 이체 요구 안 함」 https://www.tossbank.com/articles/institutionfishing

## G48 · 5장 · 크리덴셜 스터핑

- attack: `크리덴셜 스터핑` · alias: `credential stuffing`
- real (ko): 다른 사이트에서 새어 나간 아이디·비밀번호 짝을 여러 사이트에 자동으로 넣어 보며, 같은 비밀번호를 쓰는 계정을 찾아내요.
- real (en): Attackers automatically try username and password pairs leaked from one site on many other sites, looking for accounts that reuse the same password.
- todo (ko): 사이트마다 다른 비밀번호를 쓰고, 다중 인증(MFA)을 켜요.
- todo (en): Use a different password for every site and turn on multi-factor authentication.
- search (ko): `크리덴셜 스터핑`, `비밀번호 재사용` · (en): `credential stuffing`, `password reuse`
- 출처: OWASP Credential Stuffing Prevention Cheat Sheet — https://cheatsheetseries.owasp.org/cheatsheets/Credential_Stuffing_Prevention_Cheat_Sheet.html

## G49 · 6장 · 확장자 위장

- attack: `이중 확장자 위장` · alias: `double file extension`
- real (ko): `청구서.pdf.exe`처럼 이름 끝에 진짜 종류(실행 파일)를 숨겨, 문서인 줄 알고 열면 프로그램이 실행돼요. 끝 확장자가 화면에서 감춰지면 더 속기 쉬워요.
- real (en): A name like `invoice.pdf.exe` hides the real type (a program) at the very end, so opening what looks like a document runs a program. It is easier to fall for when the last extension is hidden on screen.
- todo (ko): 컴퓨터에서 「파일 확장자 표시」를 켜고, 이름의 맨 끝 확장자를 확인해요.
- todo (en): Turn on "show file extensions" and always check the very last extension of a file name.
- search (ko): `이중 확장자`, `확장자 숨기기 해제` · (en): `double file extension`, `show file extensions`
- 출처: MITRE ATT&CK T1036.007 Masquerading: Double File Extension — https://attack.mitre.org/techniques/T1036/007/

## G50 · 7장 · 비슷한 주소

- attack: `타이포스쿼팅` · alias: `typosquatting`
- real (ko): 진짜 주소와 한두 글자만 다른 주소(숫자 1과 글자 l 바꾸기 등)를 만들어 두고, 잘못 들어온 사람에게 가짜 로그인 화면을 보여 줘요.
- real (en): Attackers register addresses that differ from the real one by a character or two (like swapping the digit 1 for the letter l) and show a fake login page to anyone who lands there.
- todo (ko): 주소를 한 글자씩 확인하고, 자주 가는 곳은 즐겨찾기로 들어가요.
- todo (en): Check the address character by character, and use bookmarks for sites you visit often.
- search (ko): `타이포스쿼팅`, `유사 도메인` · (en): `typosquatting`, `lookalike domain`
- 출처: CISA Domain Doppelgänger(유사 도메인·타이포스쿼팅 탐지 서비스) — https://www.cisa.gov/resources-tools/services/domain-doppelganger ; CISA 권고 AA23-025A(유사 도메인을 쓴 피싱) — https://www.cisa.gov/news-events/cybersecurity-advisories/aa23-025a

## G51 · 8장 · 개인정보 노출

- attack: `개인정보 마스킹` · alias: `data masking`
- real (ko): 화면이나 문서에 전화번호·주소를 가리지 않고 다 보여 주면, 볼 필요 없는 사람에게까지 개인정보가 새어 나가요. 그래서 일부를 `*`로 가리는 「마스킹」을 해요.
- real (en): Showing full phone numbers or addresses on screens and documents leaks personal data to people who don't need it, so services hide part of it with `*` ("masking").
- todo (ko): 내 정보를 보낼 때도 꼭 필요한 항목만 보내고, 화면 캡처를 공유하기 전에 개인정보를 가려요.
- todo (en): Share only the details that are really needed, and hide personal data before sharing screenshots.
- search (ko): `개인정보 마스킹`, `개인정보 최소 처리` · (en): `data masking`, `data minimization`
- 출처: 개인정보보호위원회 고객센터 점검·개선 권고(가림 처리=마스킹, 불필요한 조회·노출 제한) — 바이라인네트워크 2026-10-29 https://byline.network/2026/10/29-571/ ; 「개인정보의 안전성 확보조치 기준」 출력 시 최소 항목 — 법률신문 https://www.lawtimes.co.kr/news/articleView.html?idxno=228195

## G52 · 9장 · 가짜 패키지

- attack: `패키지 타이포스쿼팅` · alias: `package typosquatting`
- real (ko): 인기 있는 프로그램 꾸러미와 이름이 한두 글자 다른 가짜 꾸러미를 올려 두고, 철자를 잘못 친 개발자가 설치하면 악성 코드가 함께 들어와요. 소프트웨어 공급망 공격의 한 갈래예요.
- real (en): Attackers publish fake packages whose names differ from popular ones by a letter or two; a developer who mistypes the name installs malicious code. It is one kind of software supply chain attack.
- todo (ko): 설치할 꾸러미 이름을 공식 문서에서 복사하고, 허락된 목록에 있는 것만 써요.
- todo (en): Copy package names from official docs, and only use packages on an approved list.
- search (ko): `패키지 타이포스쿼팅`, `소프트웨어 공급망 공격` · (en): `package typosquatting`, `software supply chain attack`
- 출처: OpenSSF Package Analysis 발표(발견된 악성 꾸러미 대부분이 의존성 혼동·타이포스쿼팅) — Google 보안 블로그 https://security.googleblog.com/2022/04/the-package-analysis-project-scalable.html ; 보도 SecurityWeek https://www.securityweek.com/new-openssf-project-hunts-malicious-packages-open-source-repositories

## G53 · 10장 · 랜섬웨어와 백업

- attack: `랜섬웨어` · alias: `ransomware`
- real (ko): 파일을 암호화해 열지 못하게 만든 뒤 돈을 요구해요. 연결된 백업까지 찾아 지우거나 잠그려 하기 때문에, 떨어뜨려 둔 백업이 중요해요.
- real (en): Ransomware encrypts files so you can't open them, then demands payment. It often hunts for connected backups to delete or lock them too, so a separate backup matters.
- todo (ko): 중요한 파일은 연결을 끊은 곳에 따로 백업해 두세요. 돈을 내도 파일을 돌려받는다는 보장은 없어요.
- todo (en): Keep a backup of important files somewhere disconnected. Paying does not guarantee you get your files back.
- search (ko): `랜섬웨어 백업`, `오프라인 백업` · (en): `ransomware offline backup`, `StopRansomware`
- 출처: CISA #StopRansomware Guide(오프라인·암호화 백업, 몸값 지불 비권고·복구 보장 없음) — https://www.cisa.gov/stopransomware/ransomware-guide ; CISA Ransomware FAQ — https://www.cisa.gov/stopransomware/ransomware-faqs

## G54 · 11장 · 파일 변조 확인

- attack: `무결성 검사 없는 다운로드` · alias: `file integrity check`
- real (ko): 받은 파일이 중간에 바뀌었어도 겉모습은 같아 보여요. 실제로는 프로그램이 파일 내용으로 「지문」(해시)을 계산해, 공식 사이트에 적힌 지문과 한 글자라도 다르면 바뀐 파일로 봐요.
- real (en): A file changed on the way can look exactly the same. In practice a program computes a "fingerprint" (hash) from the file's contents, and if it differs from the one on the official site by even one character, the file was changed.
- todo (ko): 프로그램은 공식 사이트에서 받고, 지문(SHA-256)이 적혀 있으면 비교해 봐요.
- todo (en): Download software from the official site, and compare the fingerprint (SHA-256) when one is published.
- search (ko): `파일 해시 확인`, `무결성 검증` · (en): `verify checksum SHA-256`, `file integrity`
- 출처: 「소프트웨어 개발보안 가이드」(행정안전부·KISA, 2021) 구현단계 15 「무결성 검사 없는 코드 다운로드」(프로젝트 문서) ; 해시는 같음을 확인할 뿐 안전 판정은 아님 — FOSSHub 안내 https://www.fosshub.com/resources/security/verify-downloads/

## G55 · 12장 · 스미싱

- attack: `스미싱` · alias: `smishing`
- real (ko): 택배·청첩장·과태료처럼 일상적인 문자인 척 링크를 보내, 누르면 가짜 사이트로 가거나 악성 앱이 설치돼요.
- real (en): Text messages pretending to be everyday notices (deliveries, invitations, fines) carry a link that leads to a fake site or installs a malicious app.
- todo (ko): 문자 속 링크는 누르지 말고, 의심되면 KISA 「보호나라」에서 확인하거나 118에 물어봐요.
- todo (en): Don't tap links in unexpected texts; check suspicious messages with your country's official scam-check service.
- search (ko): `스미싱`, `보호나라 스미싱 확인` · (en): `smishing`, `SMS phishing`
- 출처: 「2026 국가정보보호백서」 영문본 3부 5장(Smishing Response: 신뢰할 만한 사람·기업·기관을 사칭한 문자로 악성 앱 설치 유도, 보호나라 카카오톡 확인 서비스)(프로젝트 문서) ; KISA 스미싱·큐싱 공격 대응 — https://www.kisa.or.kr/1020601

## G56 · 13장 · 큐싱

- attack: `큐싱` · alias: `QR phishing (quishing)`
- real (ko): QR코드 안에 가짜 사이트나 악성 앱 주소를 숨겨 두고 찍게 만들어요. 길거리 안내판이나 킥보드에 가짜 QR 스티커를 덧붙이기도 해요.
- real (en): A QR code hides the address of a fake site or malicious app and tricks you into scanning it. Fake QR stickers are sometimes stuck over real ones on signs or rental scooters.
- todo (ko): QR을 찍은 뒤 열기 전에 주소의 도메인을 확인하고, 덧붙인 스티커는 의심해요.
- todo (en): After scanning, check the domain in the address before opening it, and be suspicious of stickers placed over a code.
- search (ko): `큐싱`, `QR코드 피싱` · (en): `quishing`, `QR code phishing`
- 출처: 「2026 국가정보보호백서」 영문본(QRishing 확인 서비스 추가)(프로젝트 문서) ; KISA 큐싱 경고 — 뉴시스 2026-01-13 https://www.newsis.com/view/NISX20260112_0003472942 ; KISA 스미싱·큐싱 공격 대응 — https://www.kisa.or.kr/1020601

## G57 · 14장 · 스크립트 주입

- attack: `크로스 사이트 스크립팅(XSS)` · alias: `cross-site scripting (XSS)`
- real (ko): 게시글이나 댓글에 스크립트를 섞어 두고, 사이트가 그 글을 그대로 화면에 넣으면 다른 사람의 브라우저에서 그 스크립트가 실행돼요.
- real (en): An attacker hides a script in a post or comment; if the site puts that text on the page as-is, the script runs in other people's browsers.
- todo (ko): 만드는 쪽은 사용자가 쓴 글을 화면에 넣기 전에 `<` 같은 글자를 안전한 글자로 바꿔요. 쓰는 쪽은 이상한 링크·팝업이 뜨는 게시판을 조심해요.
- todo (en): Builders should encode characters like `<` before putting user text on a page; users should be wary of boards that show odd links or pop-ups.
- search (ko): `XSS`, `출력 인코딩` · (en): `cross-site scripting`, `output encoding`
- 출처: OWASP Cross Site Scripting Prevention Cheat Sheet — https://cheatsheetseries.owasp.org/cheatsheets/Cross_Site_Scripting_Prevention_Cheat_Sheet.html

## G58 · 15장 · 불가능한 이동

- attack: `불가능한 이동 탐지` · alias: `impossible travel`
- real (ko): 한 계정이 서울에서 로그인하고 얼마 안 돼 아주 먼 나라에서 또 로그인하면, 사람이 이동할 수 없는 시간이라 비밀번호가 새어 나간 신호로 봐요.
- real (en): If one account signs in from one city and soon after from a country far away, no person could travel that fast, so it is treated as a sign the password leaked.
- todo (ko): 「새 기기·새 위치 로그인」 알림을 켜 두고, 모르는 로그인이 보이면 바로 비밀번호를 바꿔요.
- todo (en): Turn on new-device and new-location sign-in alerts, and change your password right away if you see a sign-in you don't recognize.
- search (ko): `불가능한 이동 로그인`, `비정상 로그인 탐지` · (en): `impossible travel`, `atypical travel sign-in`
- 출처: Microsoft Entra ID Protection 위험 탐지(Impossible travel·Atypical travel) — https://learn.microsoft.com/en-us/entra/id-protection/concept-identity-protection-risks

## G59 · 16장 · 비밀번호 평문 저장

- attack: `비밀번호 평문 저장` · alias: `plaintext password storage`
- real (ko): 서비스가 비밀번호를 그대로 저장해 두면, 데이터베이스가 유출되는 순간 모든 비밀번호가 그대로 드러나요. 그래서 되돌릴 수 없는 해시로 바꿔 저장해야 해요.
- real (en): If a service stores passwords as they are, every password is exposed the moment its database leaks. Passwords should be stored as one-way hashes instead.
- todo (ko): 유출 소식이 나온 사이트의 비밀번호는 바로 바꾸고, 같은 비밀번호를 쓰던 다른 곳도 바꿔요.
- todo (en): When a site announces a leak, change that password right away, and anywhere else you reused it.
- search (ko): `비밀번호 해시 저장`, `중요정보 평문저장` · (en): `password hashing`, `plaintext password`
- 출처: 「소프트웨어 개발보안 가이드」 2.7 중요정보 저장(사례1: 중요정보 평문저장)(프로젝트 문서) ; OWASP Password Storage Cheat Sheet — https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html

## G60 · 17장 · 포트 스캔

- attack: `포트 스캔` · alias: `port scanning`
- real (ko): 공격하기 전에 한 곳에서 여러 포트(서비스의 문 번호)를 차례로 두드려 어떤 서비스가 열려 있는지 알아봐요. 실제 공격보다 먼저 오는 「정찰」이에요.
- real (en): Before attacking, one source knocks on many ports (service door numbers) in turn to learn which services are open. It is reconnaissance that comes before the real attack.
