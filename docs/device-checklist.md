# 실기기 확인 목록 — 리아와 파이썬! v0.1 (아이폰 17 · 사파리)

개발 환경에는 사파리 엔진(WebKit)과 실제 아이폰이 없어서, 아래 항목은 **직접 아이폰에서 확인**해 주셔야 해요. 화면 시험은 Chromium(크롬의 바탕 브라우저)에 아이폰 17 화면 크기만 입혀서 했어요.

## 준비

1. `python3 build.py`로 만든 `dist/` 폴더를 HTTPS(자물쇠가 있는 주소) 웹 공간에 올려요. 홈 화면 앱과 오프라인 저장은 HTTPS에서만 동작해요.
2. 아이폰 17의 **사파리**로 그 주소를 열어요. (다른 앱 안의 브라우저 말고 사파리)
3. 처음 확인할 때는 「설정 → 앱 → Safari → 방문 기록 및 웹 사이트 데이터 지우기」로 깨끗한 상태에서 시작하면 좋아요.
4. 시간을 잴 때는 아이폰 시계 앱의 스톱워치를 쓰면 충분해요.

| 3 | **파이썬 준비 시간 (두 번째부터)** | 사파리를 완전히 닫고 다시 열어 같은 방법으로 | 2초 안쪽 | 걸린 초 |

| 7 | **설치 안내 (한 번만)** | 깨끗한 상태에서 첫 레슨(1-1)을 끝내요. 그다음 레슨도 하나 끝내요 | 첫 레슨 직후 「홈 화면에 추가」 안내가 한 번 뜨고, 두 번째에는 뜨지 않음 | 안 뜸 / 매번 뜸, 캡처 |

## 알려 주는 방법

- 항목 번호와 **정상 / 이상**만 적어 주셔도 돼요. 예: 「1 정상(1.2초), 2 와이파이 8초·LTE 15초, 6 이상 — 제출 버튼이 키보드에 가려짐(캡처 첨부)」

- 아이폰의 iOS 버전(「설정 → 일반 → 정보 → iOS 버전」)도 함께 알려 주세요.
