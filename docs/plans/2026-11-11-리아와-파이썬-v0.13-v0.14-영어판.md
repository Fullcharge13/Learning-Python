# 「리아와 파이썬!」 v0.13.0~v0.14.0 계획서 — 영어판

**Goal**: 해외 영어 학습자가 한글 없이 1~17장·심화·매일 도전·텃밭을 배울 수 있는 영어판을 만들고 v0.14.0에서 공개한다.
**Architecture**: 한국어 문구는 코드 자리에 두고 열쇠로 쓰며(gettext 방식 `t\`…\``), 영어 표·영어 레슨은 따로 빌드해 고른 언어만 불러온다. 레슨은 장마다 같은 모양의 영어 파일을 두고 짝 시험으로 지킨다.
**Spec**: `docs/specs/2026-11-11-영어판-설계.md`
**Global Constraints**: 첫 파일 800KB(C68) · saveVer 2 그대로 · 공개 전 English는 개발자 모드만(`EN_PUBLIC`) · 커밋·푸시·반영은 판마다 보고 뒤 사용자 승인 · 커밋 작성자 Claude
**Review Focus**
1. 영어로 바꾼 예제 코드의 실제 출력 ≠ 정답 → 짝 시험이 모든 영어 장의 코드를 실행(작업 2~5)
2. 화면에 `t` 없이 남은 한글 → 문구 빠짐 시험 + 영어 화면 순회의 「한글 없음」 검사(작업 1)
3. 언어를 바꾸면 진도·저장이 깨짐 → 언어 전환 화면 시험(작업 1)
4. 텃밭이 영어 작물 이름에서 결과 대조(C62)에 걸림 → pytest 두 언어 + 주문 정답 영어 29/29(작업 6)
5. 긴 영어 문구로 화면 넘침 → 영어 화면 순회 넘침·작은 단추 검사(작업 1·7)
