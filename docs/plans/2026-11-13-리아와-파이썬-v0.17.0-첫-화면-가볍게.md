# 첫 화면 가볍게 (v0.17.0) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 코드 편집기와 오류 안내를 첫 파일에서 떼어 첫 파일을 520KB 이하로 줄이고, 느린 휴대폰에서도 첫 화면이 지금보다 빠르게 한다.

**Architecture:** 새 `src/chunks.js`가 「묶음」(편집기·오류 안내)을 받는다. 배포판에서는 빌드가 넣은 `window.RIA_CHUNKS` 주소를 `import()`하고, 개발판에서는 `src/chunkdev.js`의 글자 그대로 import를 쓴다(배포판에서는 `lessondev`처럼 빈 모듈로 바꿔 끼움). 세 편집기 화면은 새 도우미 `mountEditor`로 편집기를 기다리며, 오류 카드는 `ensureErrorData()`를 기다린다. `build.py`가 두 묶음을 `js/<이름>-<지문8>.js` ESM 파일로 내보내고 `sw.js`가 미리 받아 저장한다.

**Tech Stack:** 기존 그대로(esbuild, Playwright, pytest, node:test). 새 의존성 없음.

**Spec:** `docs/specs/2026-11-13-첫-화면-가볍게-설계.md`

## Global Constraints

- 작업 브랜치 로컬 `feature/first-screen-light`(89886fb에서). **푸시·합치기 금지**(사용자 승인 뒤 컨트롤러).
- 첫 파일 **≤ 520KB** 목표, 새 한도 **600KB(614,400B)**. 편집기 묶음 **≤ 420KB(430,080B)**, 오류 안내 묶음 **≤ 40KB(40,960B)**.
- 묶음 파일 이름 `js/editor-<지문8>.js`, `js/errors-<지문8>.js`(지문 = 내용 sha256 앞 8자). 첫 파일의 이름표 `window.RIA_CHUNKS = { editor: "...", errors: "..." }`.
- 편집기 묶음은 앱의 `src/i18n.js`를 묶지 않는다(언어 상태 한 벌). 오류 묶음은 데이터만.
- 기능·문구·저장 형식 변경 없음(`saveVer` 2). 새 화면 문구는 아래 것들뿐, 모두 `t```, 영어는 `i18n/en/ui.*.json`:
  「코드 입력창 준비 중…」, 「코드 입력창을 불러오지 못했어요. 인터넷에 연결한 뒤 다시 열어 주세요」, 「다시 시도」, 「새 판이 나왔어요. 새로 고침하면 열려요」, 「새로 고침」, 「단서 찾는 중…」, 그리고 오류 묶음 실패 때 간단 카드 제목·본문 2개(「{type} 오류」, 「{line}번째 줄 근처를 살펴보세요」 — 줄 번호 없으면 「코드를 살펴보세요」).
- iOS Safari 16 이상, 단일 HTML·Blob 작업자 구조 유지. `README.md`는 `tools/readme_gen.py`로만.
- 판정은 `docs/plans/ledger.md`의 「v0.17.0」 표에 F-C1 … 번호로.

### Task 2: 편집기 기다리기 (화면 쪽, 아직 한 파일)

**Files:** Create `src/chunks.js`, `src/chunkdev.js`, `src/ui/editorslot.js` · Modify `src/ui/editor.js`(i18n import 없애고 `label`을 꼭 받음), `src/ui/write.js`, `src/ui/guard.js`, `src/ui/garden.js`, `src/app.js`(첫 화면 뒤 쉬는 틈 미리 받기), `src/style.css`, `i18n/en/ui.*.json` · Test `tests/unit/chunks.test.js`, `tests/flow.py`

**Interfaces:**
- Produces:
  - `src/chunks.js`: `loadChunk(name: "editor"|"errors") -> Promise<module>` — `window.RIA_CHUNKS?.[name]`가 있으면 `import(new URL(그 주소, location.href).href)`, 없으면 `chunkdev.js`의 `devChunk(name)`. 같은 이름은 한 번만 받고 약속을 재사용, 실패하면 약속을 지워 다시 시도 가능. `prefetchChunks()` — `requestIdleCallback`(없으면 `setTimeout` 1500ms)으로 두 묶음 `loadChunk`.
  - 실패 구분: `ChunkMissingError`(404 등, 업데이트 뒤 옛 탭) vs 그 밖(네트워크). `loadChunk`가 던지는 오류의 `.kind`가 `"stale"` 또는 `"offline"`.
  - `src/chunkdev.js`: `devChunk(name)` — `name === "editor" ? import("./ui/editor.js") : import("../data/errors.js")`.
  - `src/ui/editorslot.js`: `mountEditor(slot: HTMLElement, opts: { doc, label, onChange, margins, onReady?: (ed) => void }) -> Promise<Editor>` — 즉시 `slot`에 읽기 전용 `<pre>`(시작 코드) + 「코드 입력창 준비 중…」 덮개, `loadChunk("editor")` 뒤 `createEditor(slot, opts)`로 바꿔 끼움. 실패면 `kind`에 따라 「코드 입력창을 불러오지 못했어요…」+「다시 시도」 또는 「새 판이 나왔어요…」+「새로 고침」(`location.reload()`).
  - 세 화면은 편집기가 오기 전 「실행」「제출」·기호 줄을 `disabled`로, 오면 켬(파이썬 준비 상태와 둘 다 만족할 때만 켬).
