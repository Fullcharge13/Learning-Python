## 3. 굳어진 구조(다음 기능이 기대는 것)

- **빌드**: `src/` 여러 파일 → `build.py`(esbuild) → `dist/index.html` 한 장 + `lessons/chN-<해시>.json` + `sw.js`. 배포는 gh-pages 브랜치.
- **파이썬 실행**: Pyodide 314.0.7을 Web Worker에서. 채점은 `src/py/runner.py`의 `run(code, stdin, require, files, server)` — 출력 비교 + `require`(꼭 쓸 문법: AST 이름, `Call:`·`Method:`·`Def:`·`SQL:` 등). 시간 제한·무한 반복 보호 있음.
- **가상 세계**: 가상 파일(`files`), 연습 서버(`server`, 주소 → 응답 표), 차트 모듈(`chart.bar/line/legend…`)을 파이썬 안에 끼워 넣는 방식이 이미 있다. → **게임 세계(농장 등)도 같은 방식으로 파이썬 모듈로 끼워 넣을 수 있다.**
- **레슨 데이터**: 장 파일의 `LESSONS`·`ADVANCED`·`TEMPLATES` 표. 엔진은 표만 읽는다.
- **점검기** `tests/content.py`: 장마다 쓸 수 있는 문법 범위(누적), 38칸 코드 폭, 문장 길이, 정답·starter·베끼기 답 검사, 문제 틀 100가지 생성 검사.
- **저장**: `localStorage` 한 칸, `saveVer 2`, 옛 저장 옮기기 코드.
- **시험 묶음**: 단위(Node) 371 · 파이썬 81 · 점검 규칙 149 · 차트 13 · 채점(브라우저) 31 · 빌드 27 · 화면 순회 17 · 경제 시뮬레이션.

## 4. 일하는 방식(이 프로젝트에서 정착한 것)

- 큰 판: 디딤돌·설계 조사(Opus) → 엔진(Opus, 시험 먼저) → 내용 쓰기(Sonnet 여러 명 동시) → 검토 2명(Opus) → 전체 시험·실제 앱 → 사용자 「커밋 후 반영」 허락 → main + gh-pages.
- 본 과정 보강은 **더하기만**(기존 카드·문제·직접 작성·장 평가 그대로), 보강 레슨에 `updated` 표시.
- 같은 장 파일을 여러 작성자가 고칠 때는 작은 Edit만(전체 바꾸기 금지, C58).
- 남의 캐릭터·로고 금지, 파이썬 상표는 교육용 무료 이름으로 사용.
