## 2. 보강 표 (6레슨, C48·C49 그대로)

모두 `updated: "v0.9"`, 카드 3번째로 1장 + 터치 문제를 기존 뒤에 덧붙임(C48: 카드 ≤3, 터치 ≤7) + 요약 4번째 줄(C49). 기존 카드·문제는 바꾸지 않는다.

| 레슨 | 더하는 디딤돌 | 카드 예 | 터치(현재→상한) | 요약 4번째 줄(안) | 쓰는 곳 |
|---|---|---|---|---|---|
| 5-1 while로 반복하기 | **`+=`·`-=`**(4절) = `n = n + 1`의 줄임 | `n = 3` / `while n > 0:` / `print(n)` / `n -= 1` · `total = 0` / `total += 5` / `total += 3` / `print(total)` → 8 | 5→7, **1~2개**(blank 칩 `+=`·`=+`·`==` — `=+ 1`은 「+1을 넣기」라 다른 출력) | `n += 1`은 `n = n + 1`의 줄임 | 13-5·14-2·15-3·15-5 본 과정, 13~17 심화 전부 |
| 7-4 정렬과 복사 | 리스트 슬라이싱 `b[:2]`·`b[2:]`(새 리스트) | `a = [5, 1, 4, 2]` / `b = sorted(a)` / `print(b[:2])` → `[1, 2]` | 6→7, **1개** | 리스트도 `a[:2]`로 잘라 새 리스트 | 17-A2·A3 |
| 14-1 JSON 읽고 쓰기 | JSON `null` → `None`, `if 값:`으로 확인(12-1 `if m:`과 같음) | `d = json.loads('{"next": null}')` / `print(d["next"])` → None / `if not d["next"]:` / `print("마지막 쪽")` | 5→7, **1~2개** | JSON null은 None, `if`로 있는지 확인 | 14-A1, 16-A1(LEFT JOIN을 쓸 때) |
| 15-2 `__init__`와 속성 | 객체를 리스트에 담아 for로 돌기 | `cats = [Cat("나비"), Cat("모모")]` / `for c in cats:` / `print(c.name)` | 5→7, **1~2개** | 객체도 리스트에 담아 for로 돌기 | 15-A1·A2·A3 |
| 15-3 메서드 | 속성에 빈 리스트, 메서드에서 `self.items.append(x)` | `class Cart:` / `__init__`에서 `self.items = []` / `def add(self, x): self.items.append(x)` / `c.add("빵")` ×2 / `print(len(c.items))` → 2 | 5→7, **1~2개** | `self.items = []`에 메서드로 담기 | 15-A2·A3 |
| 16-3 정렬과 집계 | `SUM`·`MAX`·`MIN` | `CREATE TABLE t (n)` + `executemany`로 3, 8, 5 / `SELECT SUM(n), MAX(n), MIN(n) FROM t` / `print(cur.fetchone())` → `(16, 8, 3)` | 5→7, **1~2개** | SUM 합계, MAX·MIN 가장 큰·작은 값 | 16-A2·A3 |

- 직접 작성 문제·장 평가(x-5)는 그대로.
- **5-3이 아니라 5-1인 이유**: 5-3(합계 모으기)이 더 어울리지만 이미 v0.7.1 보강으로 카드 3·터치 7·요약 4줄이라 C48 상한에 닿아 더할 수 없다. 5-1은 `n = n - 1`·`i = i + 1`이 바로 위 카드에 있어 「줄인 모양」을 옆에 두기 좋다.
- 심화 첫 카드의 이어 주는 한 줄 예: 「15-2에서 객체를 리스트에 담아 돌았죠?」, 「14-1에서 null이 None이 되는 걸 봤어요.」
- 넣지 않은 것(심화가 직접 가르침): 쿼리 직접 붙이기·쪽 번호 반복, 상태 코드 갈래, `json.dump/load`, `__str__`·`__eq__`, 클래스 이름으로 속성 바꾸기, JOIN·HAVING, 여러 선·`legend`.

## 3. 점검기·엔진

### 3-1. 본 과정에 새로 허용할 문법: **없음** (좁힐 것 2개)

| `AugAssign` | 2장부터 허용 | 1~12장 본 과정·심화 사용 0, 13장부터 사용(4절) | 5-1 보강과 함께 **5장부터 허용**(2~4장에서 막아도 깨지는 레슨 없음) |

## 4. `+=` 문제

**본 과정 코드에 나오는 곳(11줄, 5레슨)** — 말풍선·해설·요약 어디에서도 `+=`를 설명하지 않음(검색 0). 1~12장은 본 과정·심화 모두 0건(ch8 머리 주석 「+=는 아직 없다」).

| 레슨 | 자리 | 줄 |
|---|---|---|
| 13-5 평가 | write 정답 | `text += " (따뜻하게!)"` (문자열 `+=`) |
| 14-2 | blank 문제 코드(학습자가 읽음) | `total += n` |
| 14-2 | write 정답 | `total += o["price"] * o["qty"]` |
| 15-3 | **카드 1**, 문제 2·4, write 정답 | `self.balance += n`, `self.n += 1`, `self.balance -= n` |
| 15-5 평가 | 카드 1, write 정답 | `self.sum += price` |

**선택지**

| | 방법 | 장점 | 단점 |
|---|---|---|---|
| A **(추천)** | 5-1 보강으로 `+=`·`-=`를 가르치고(2절), 점검기 `AugAssign`을 5장부터 | 실제 코드에서 가장 흔한 모양(특히 `self.balance += n`), 고칠 곳 1레슨, 13~17장 심화도 자유롭게 씀, 매일 도전 틀에도 씀 | 5-1을 끝낸 학습자에게 「새 내용」 점(의도한 동작) |
| B | 11줄을 `x = x + …`로 바꿈 | 새 개념 없음 | 평가 레슨 2개 포함 5레슨 수정, 클래스 코드가 길어짐(38칸), 바깥 코드에서 `+=`를 만나면 처음 봄 |
| C | 14-2(첫 「읽는」 자리)에 카드 | 쓰는 곳 가까이 | 13-5 정답이 그보다 앞섬, 장 주제와 무관한 카드 |

- 5-3이 상한이라 5-1에 둠(2절). 문자열 `+=`(13-5)는 5-1 카드 말풍선에 「글자에도 돼요」 한마디로 덮는다.
- A를 고르면 가이드의 「`+=` 대신 `total = total + x`」 문장(3-3절 「안다고 가정하지 않음」)을 「5-1에서 배움」으로 고친다.

## 5. 작성자 메모(장마다 「이것은 안다고 가정하지 않음」)

**공통(1~12장 심화를 건너뛴 학습자)**: 서식 지정자 `:.1f`·`:>5`(→ `round`·`zfill`·`center`), `"""…"""`, `divmod`, `a if c else b`, `match`, 기본값 매개변수·재귀, `for…else`, `join`·`ljust`·`rjust`·`title`, **컴프리헨션(7-A1)**, **lambda(9-A1, → `def` 함수 이름)**, `max(…, key=)`, `except (A, B)`, `csv.writer`(11-A2), 이름 붙인 묶음 `(?P<…>)`(12-A1) 모두 쓰지 않음. `enumerate`·`zip`은 점검기 오류. `+=`는 5-1 보강이 들어간 뒤에만. `isinstance`·`extend`·`is None`도 쓰지 않음(`if 값:`·`if not 값:`으로).

- **13장**: 연습 서버는 **주소 글자가 정확히 같을 때만** 답하고(쿼리 순서까지), **상태가 없다**(같은 주소는 늘 같은 답 → 「503이면 다시 시도」는 성공하지 않음, 다시 시도를 보이려면 다른 주소로). 한 문제 서버 표는 **최대 8개**이고 write 시험마다 따로 둘 수 없다(`server`는 시험별 칸 아님) → 숨은 시험은 stdin으로 다른 주소·값을 고르게. 쿼리 값은 영문·숫자만(한글은 `%EB…`로 바뀌어 서버 표 열쇠도 그 모양이어야 함). A1은 `urlencode` 없이 붙이고 `parse_qs`(13-1)로 되읽어 확인. A3은 13-4(링크 따라가기)와 겹치지 않게 「`?page=` 늘리기 + 404에서 멈추기」. 페이지는 3~4쪽이면 8칸 안에 든다.
- **14장**: A1(쪽 나뉨)은 13-A3과 구분: 멈출 때를 **데이터**(`"next": null` 또는 `"pages": 3`)로 안다. `null`은 14-1 보강에서 이어 줌. A2 출력은 가이드 3-1(JSON 출력): `dumps`/파일 내용을 보일 때 `sort_keys=True`·`indent=2`·`ensure_ascii=False`를 모두 적고 과제 문장에도 적는다. 파일은 실행이 끝나면 사라지므로 같은 실행에서 쓰고 읽는다. `json.dump/load`를 열지 않기로 하면 `f.write(json.dumps(…))`. A3 평균은 `round(…, 1)`.
- **15장**: `print(객체)`의 기본 출력 `<__main__.Book object at 0x…>`는 **주소가 실행마다 달라** 카드 `out`·choice 보기·write 기대 출력에 쓰지 않는다(말로만 「알아보기 어려운 글자」). `print([b1, b2])`처럼 객체 리스트를 통째로 찍으면 `__str__`이 아니라 `__repr__`이 쓰여 역시 주소가 나옴 → for로 하나씩. `__eq__`를 정의하면 그 객체는 집합·딕셔너리 열쇠로 못 씀(`__hash__`가 사라짐) → 넣지 않음. `__eq__` 안에서 `isinstance` 쓰지 않음(같은 클래스끼리만 비교하는 예로). A2 함정(`self.count += 1`은 그 객체에만 새 속성)은 choice로 내기 좋음. 15-2·15-3 보강(객체 리스트, `self.items = []`)에서 이어 줌. 상속은 하나만, `super().__init__`(15-4).
- **16장**: 언제나 `":memory:"`, 한 코드에서 `CREATE` → `INSERT` → `SELECT`. 여러 줄 결과는 **`ORDER BY` 필수**(JOIN·GROUP BY 결과 포함, 같은 값이면 둘째 기준까지). INNER JOIN만(LEFT JOIN을 쓰면 빈칸이 `None`으로 찍힘을 카드에서). `AVG`는 긴 소수 → 파이썬 `round`. `SUM`·`MAX`·`MIN`은 16-3 보강에서 이어 줌. 열 이름 별칭(`AS`)·`ROUND()`·하위 질의는 본 과정에 없음 → 쓰지 않거나 카드로. 하드코딩 막기: 표 내용은 `files`의 CSV로(시험마다 다른 CSV, 16-2·16-3 write 방식) + `require`에 `SQL:JOIN`/`SQL:HAVING`. 38칸 때문에 SQL은 괄호 안 글자 잇기로 나눔(16장 모양 그대로).
- **17장**: 한 그림 점 **24개까지**, 한 실행 그림 **3개까지**, 선은(엔진 작업 뒤) **3개까지**. A1은 같은 이름들에 `line` 두 번 → `legend` → `show` 한 번, matplotlib 대응은 `plt.plot` 두 번 + `plt.legend([...])`(17-5 `show_only` 카드 방식). A2 거르기는 `range(len(…))` + `if` + 두 리스트에 `append`(7-2·7-3), 정렬은 `def` 함수 + `key=`(9-3), 앞 몇 개는 7-4 보강의 리스트 슬라이싱. A3 한 달 기록은 CSV(최대 5파일)로 주고, 날짜별 31점이 아니라 주별(`(day - 1) // 7`)·종류별로 묶어 그림 2~3개. 차트 채점은 `chart` 칸 목록(그림 차례대로).
