# 첫 사용 튜토리얼 — 설계서 (v0.18.0 후보)

날짜: 2026-11-13 · 브랜치: `feature/first-run-tutorial` (`feature/guard-room` d393d75에서)

## 1. 왜 하나

- 사용자 요청: 처음 쓰는 사람이 언어를 고르고 「시작하기」를 누르면, 이 서비스를 어떻게 쓰는지 간단한 튜토리얼을 보여 준다. 건너뛸 수 있어야 한다.
- 사용자가 정한 성공 기준: **튜토리얼을 마친 사람은 첫 코드를 직접 실행해 봤다.**
- 사용자가 고른 방식(A): 짧은 안내 카드 + 튜토리얼 안에서 첫 코드 실행. 세부는 설계자 제안대로 진행(사용자 승인).
- 지금은 앱을 열 때마다 인사 화면(`src/ui/splash.js`) → 「시작하기」 → 홈. 처음 온 사람을 구분하지 않는다.

## 2. 목표 / 하지 않을 것 / 실패로 볼 것

**목표**
1. 처음 온 사람은 「시작하기」 뒤 튜토리얼 4장을 보고, 4장째에서 「▶ 실행」을 눌러 `print`의 결과를 본다. 1분 안팎.
2. 어느 카드에서든 「건너뛰기」로 바로 홈.
3. 이미 쓰던 사람에게는 자동으로 뜨지 않는다. 설정에서 「사용법 다시 보기」.
4. 한·영, 움직임 줄이기, 오프라인·엔진 준비 전·엔진 실패에서도 막히지 않음.

**하지 않을 것**
- XP·바이트 보상(경제 균형 그대로). 레슨·홈·텃밭·경비실 동작 변경. 저장 형식 판 번호 변경(`saveVer` 2).
- 진짜 화면 위 말풍선 안내(방식 B·C 아님).
- 튜토리얼에서 코드 편집기(CodeMirror) 사용 — 편집기 묶음을 기다리지 않는다.

**실패로 볼 것**
- 튜토리얼 때문에 첫 화면(인사 화면)이 느려진다(첫 파일 한도 600KB, v0.17.0 측정 도구로 확인).
- 엔진이 준비되지 않았거나 못 받았을 때 튜토리얼을 끝낼 수 없다.
- 이미 쓰던 사람에게 튜토리얼이 자동으로 뜬다.
- 학습자가 입력한 글이 HTML로 해석되거나(XSS), 따옴표를 깨서 다른 코드가 실행된다.

## 3. 설계

### 3-1. 언제 뜨나

- 저장에 새 칸 `tutorial`: `null`(아직) | `"done"`(끝까지) | `"skipped"`(건너뜀). 없으면 아래 규칙으로 채운다(`src/save.js`의 정리 함수, `saveVer` 그대로).
- **옛 저장 불러올 때**: `tutorial`이 없고 `completed_lessons`가 하나라도 있거나 `xp > 0`이면 `"done"`으로 채운다(이미 쓰던 사람). 아니면 `null`.
- 「시작하기」를 누를 때 `tutorial === null`이면 튜토리얼 화면, 아니면 지금처럼 홈.
- 개발자 모드 저장(검수용, 따로 저장)에서는 자동으로 띄우지 않는다(`tutorial`을 `"done"` 취급). 설정에서 다시 보기는 된다.

### 3-2. 화면 (새 화면 `src/ui/tutorial.js`, `SCREENS.tutorial`)

카드 4장, 위쪽 점 4개(지금 위치), 오른쪽 위 「건너뛰기」, 아래 「다음」. 리아 그림·말투는 기존과 같음(존댓말).

| 카드 | 리아의 말 (한국어 원문, 영어는 `i18n/en/ui.tutorial.json`) |
|---|---|
| 1 인사 | 「반가워요! 하루 10분, 첫 코드부터 같이 해요.」 |
| 2 레슨 | 「레슨은 설명 카드를 읽고, 고르기·빈칸을 풀고, 마지막에 직접 코드를 써요. 틀려도 괜찮아요. 힌트가 있어요.」 |
| 3 보상·텃밭 | 「문제를 풀면 XP와 바이트가 쌓여요. 바이트로 제 옷을 고를 수 있고, 1장을 끝내면 「파이의 텃밭」과 경비실이 열려요.」 |
| 4 첫 코드 | 「이제 진짜 코드를 실행해 볼까요? 따옴표 안의 글자를 바꿔도 돼요.」 |

4장째:
- 코드 줄: `print("` + **입력칸** + `")`. 입력칸 기본값은 「안녕하세요!」(영어 「Hello!」), 최대 30자.
- **안전**: 입력값은 실행 전에 파이썬 문자열 리터럴로 안전하게 만든다(`\`와 `"`를 이스케이프, 줄바꿈 제거). 결과는 `textContent`로만 그린다. 시험 필수(§4).
- 「▶ 실행」: 기존 `PyRun`(`app.py.run`)으로 실행, 결과 상자에 출력. 성공하면 리아가 기뻐하는 얼굴 + 「첫 코드 성공! 🎉」, 아래 단추 「1-1 시작하기」·「홈으로」.
- **엔진 준비 전**: 실행 단추 대신 진행 막대 + 「파이썬 준비 중…」(인사 화면과 같은 상태 신호 `ctx.onPy`). 준비되면 단추가 켜짐. 기다리는 동안 「건너뛰기」·「홈으로」는 됨.
- **엔진 실패**(오프라인 첫 방문 등): 「지금은 파이썬을 받지 못했어요. 1-1에서 바로 해 볼 수 있어요」 + 「홈으로」. 이때도 `tutorial = "done"`.
- 실행 중 오류는 생길 수 없게 만들었지만(입력이 문자열 안), 만약 결과에 오류가 오면 출력 대신 「다시 실행해 볼까요?」.

끝내기:
- 4장째 실행 성공 뒤 「1-1 시작하기」 → `tutorial = "done"`, 1-1 레슨 열기. 「홈으로」 → `"done"`, 홈.
- 「건너뛰기」 → `"skipped"`, 홈. 확인 창 없음.
- 도중에 앱을 닫으면 `null` 그대로(다음 「시작하기」 때 처음부터).

### 3-3. 설정에서 다시 보기

- 설정 화면에 줄 하나: 「사용법 다시 보기」 + 「보기」 단추 → 튜토리얼 화면(끝내면 설정이 아니라 홈으로). 다시 볼 때는 `tutorial` 값을 바꾸지 않는다.

- **다시 보기의 4장째 끝**(설계자 판단): 다시 보기에서는 실행 성공 뒤 「홈으로」 하나만 보인다(「1-1 시작하기」 없음). 화면은 `show("tutorial", { replay: true })`로 구분.
- **기록 값의 뜻**(설계자 판단): `tutorial`은 「다시 띄울지」만 정한다. 첫 코드를 실행했는지는 따로 기록하지 않는다(성공 기준은 흐름 시험으로 확인). 엔진 실패로 끝낸 경우 `"done"`, 「건너뛰기」는 카드 어디서든 `"skipped"`.

### 3-4. 접근성·움직임

- 카드는 `role="dialog"`가 아닌 화면(main) 하나, 점은 `aria-label`「4장 중 2장」. 단추 최소 44px.
- 카드 넘김 효과는 `prefers-reduced-motion`이면 끔.
- 화면 높이가 작은 휴대폰(iPhone SE)에서 「다음」·「건너뛰기」가 화면 안에.

### 3-5. 크기

- 튜토리얼 코드·문구는 첫 파일에 들어간다(인사 화면 바로 다음이므로). 예상 3~6KB. 첫 파일 600KB 한도 안, 여유 약 130KB.

## 4. 시험

- 단위: `tutorial` 정리 규칙(없음+기록 없음 → `null`, 없음+기록 있음 → `"done"`, 잘못된 값 → 규칙대로), 입력값 → 파이썬 문자열(따옴표·역슬래시·줄바꿈·`<script>` 포함 값이 그대로 출력되는 코드가 됨, 30자 자르기).
- 흐름(`tests/flow.py`):
  - 새 저장: 「시작하기」 → 카드 1~4 → 기본값 실행 → 결과 「안녕하세요!」 → 「홈으로」 → 저장 `tutorial == "done"`, 다음 「시작하기」는 바로 홈.
  - 입력값 `"<b>x</b>\"); print(1) #` → 결과가 그 글자 그대로(굵은 글씨 없음, `1` 줄 없음).
  - 건너뛰기(카드 2에서) → 홈, `"skipped"`.
  - 엔진 준비 전(엔진 받기를 늦춤) → 진행 막대, 준비 뒤 실행 됨. 엔진 실패(받기 막음) → 실패 문구 + 홈으로.
  - 기록 있는 옛 저장 → 바로 홈. 설정 「사용법 다시 보기」 → 튜토리얼 → 끝 → 홈, `tutorial` 값 그대로.
  - 영어판 한 번(한글 없음). 움직임 줄이기. 작은 화면(iPhone SE)에서 단추가 화면 안.
  - 「1-1 시작하기」 → 1-1 레슨 화면.
- 기존 전체 묶음 통과. v0.17.0 측정 도구로 첫 화면 시간이 v0.17.0보다 나빠지지 않음(느린 3G 행, 같은 `--runs`).

## 6. 만드는 사람에게 맡기는 것

- 카드 모양·넘김 효과(기존 카드·단추 스타일을 따름).
- 1-1 레슨을 여는 방법(기존 홈에서 레슨 여는 경로 재사용).
- 리아 표정 선택(기존 `riaSVG` 얼굴 중에서).
