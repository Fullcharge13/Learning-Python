## 1. v0.12 노드와 명령

| 장 | 노드 | 코드 | 비고 |
|---|---|---|---|
| 10 | 시도하기 / 안 되면 `try{}` (body + handler) | `try:` … `except ValueError:` … | 잡는 오류는 `ValueError` 하나(텃밭 명령이 내는 오류). 두 칸 모두 비면 검사 오류 |
| 11 | 쪽지 읽기 `readnote{file}` (body) | `with open("주문서.txt") as f:` / `    for line in f:` | 안쪽에서 값 `line`(문자열) 사용 가능. 파일은 쪽지함 목록에서 고름 |
| 11 | 줄 나누기 `splitline{}` | `crop, n = line.split()` | 쪽지 읽기 안에서만. 뒤에서 `crop`(작물 값)·`n`(글자) 사용 가능 |
| 11 | 일지 쓰기 `writelog{pre, var, post}` | `with open("농장일지.txt", "a") as f:` / `    f.write("…" + str(count) + "\n")` | 값 넣어 말하기와 같은 고르기, 줄바꿈 자동 |
| 12 | 패턴 찾기 `findall{pattern}` (body) | `for crop, n in re.findall(r"(당근|감자|토마토)\s*(\d+)", line):` | 패턴 3가지 중 고름: 작물+숫자 / 숫자만(`for n in re.findall(r"\d+", line):`) / 작물 이름만. `import re`는 코드 맨 위에 자동 한 줄 |
| 5·11 | (반복 확장) `int(n)`번 반복 | `for i in range(int(n)):` | 반복 노드의 횟수로 「값 n」을 고를 수 있음(11장 이후, `n`이 있을 때) |
| 7·11 | (심기 확장) | `plant(crop)` | `crop`이 줄 나누기·패턴 찾기에서 왔을 때도 고를 수 있음 |

- 토마토: 10장 통과 시 열림. 성장 10(비료 7). 씨앗 봉투: 처음 5개, `plant("토마토")`마다 −1, 토마토 거두기마다 +2(최대 20). 봉투가 비면 `ValueError("토마토 씨앗이 떨어졌어요")`(시간 1 소모, 사건 `plant_fail reason:"no_tomato_seed"` 후 예외).
- 새 명령 `seeds()` → 남은 토마토 씨앗 수(시간 0, 살펴보기 수에 포함, C60).
- 텃밭 오류 설명 추가: 토마토 씨앗 ValueError, `FileNotFoundError`(「쪽지함에 그 이름의 쪽지가 없어요」), 쓰기 금지 쪽지에 쓰기(`PermissionError` → 「받은 쪽지는 읽기만 해요. 쓸 수 있는 건 농장일지.txt」), `int("두")` ValueError(「숫자로 바꿀 수 없는 글자예요」).

## 2. 쪽지함 (파일)

- **받는 쪽지**(읽기 전용): 지금 주문의 `note`가 있으면 `주문서.txt`로 놓인다. 주문이 없거나 note가 없으면 「오늘의 주문서」(실행 횟수로 정해지는 고정 목록 4가지 중 하나, 예: `당근 2\n감자 1`). 12장 주문은 손글씨 쪽지 `손글씨주문.txt`(예: `리아: 당근3개 부탁! 토마토 2개도~` — 작물+숫자 패턴은 작물 바로 뒤(빈칸은 괜찮음)에 숫자가 와야 읽힘).
- **남는 파일**: `농장일지.txt` 하나만 쓸 수 있다(2000자까지, 넘으면 앞에서부터 잘림). 실행이 끝나면 엔진이 그 내용을 결과로 돌려주고 `save.garden.files`에 저장 → 다음 실행에 다시 놓인다. 다른 이름으로 쓰면 그 실행에서만 있고 사라진다(오류 아님, 쪽지함에 「저장 안 됨」 표시 없음 — 단순하게).
- 쪽지함 화면: 텃밭 위쪽 「쪽지함」 단추 → 쪽지 목록(받는 쪽지 🔒, 농장일지) → 내용 보기, 농장일지 「비우기」(확인 창).
- 엔진: `run(..., farm=state, files=쪽지들)` — 받는 쪽지는 읽기 전용으로 놓음(쓰기 열기 시 PermissionError), 실행 끝에 `농장일지.txt`를 읽어 `result.farm.files`로 돌려줌. 결과 대조(C62)에 씨앗 수 변화(토마토 심기 −1, 토마토 수확 +2, 최대 20)와 일지 길이 상한 추가.

## 4. 저장

`save.garden`에 `seeds`(토마토 씨앗, 기본 5), `files`(`{"농장일지.txt": ""}`) 추가. saveVer 그대로 2, 없으면 기본값(옛 저장 시험). 창고에 `토마토` 칸 추가(없으면 0).

## 5. 첫 파일 크기

지금 744KB / 상한 760KB. v0.12 화면을 넣으면 넘을 가능성이 크다. **판정 C68(제안)**: 상한을 800KB로 올린다(gzip 약 270KB, 휴대폰 첫 로딩에 큰 차이 없음). 텃밭 화면을 따로 불러오는 방식은 오프라인 저장·시험 묶음까지 바꿔야 해서 v0.14 전에 다시 본다. 구현 판에서 실제 크기를 보고 정한다.

## 6. 시험

pytest(토마토·씨앗·`seeds()`·읽기 전용 쪽지·일지 저장·길이 상한·결과 대조), 노드 단위(try/readnote/splitline/writelog/findall 코드·검사·값 범위 `line`·`crop`·`n`), 주문 29/29 + 실제 플레이 시뮬레이션, 상태 단위(옛 저장, 씨앗·파일 저장), 오류 설명 단위, 화면 순회(쪽지함, 새 노드 고르기 창, 아이폰 17 넘침·터치), 경제 시뮬레이션 회귀 없음, 무작위 노드 프로그램 검사(검사 통과 프로그램이 3초 안에 끝남).
