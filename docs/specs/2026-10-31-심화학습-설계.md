# 심화학습·매일 도전 설계 (리아와 파이썬! v0.7~v0.9)

- 작성일: 2026-10-31 · 상태: **확정**(2026-10-31, 장별 주제 표 포함)
- 사용자 결정: 가+다(장마다 심화 레슨 + 매일 도전) / 심화는 장 평가 통과 즉시 열림 / 매일 도전은 3문제·5분 + 보너스

## 1. 심화 레슨

- 장마다 3개, id는 `7-A1`·`7-A2`·`7-A3`(A = Advanced). 전체 17 × 3 = **51레슨**.
- **열림**: 그 장 평가(x-5)를 통과하면 바로. 심화는 **선택**이라 건너뛰어도 다음 장은 열린다.
- **학습 길**: 장 평가 노드 옆으로 갈라지는 작은 가지(별 모양 노드 3개). 설정 「학습 내용」에는 장마다 「심화 n/3」.
- **형식**: 지금 레슨과 같다(카드 + 터치 + 직접 작성 1). 평가 레슨은 없음. A3은 그 장의 작은 「응용 과제」.
- **보상**: 처음 끝내면 XP 15 · 바이트 15(보통 레슨 10·10보다 조금 많게). 장의 심화 3개를 다 끝내면 그 장에 별 표시. 배지 2개 추가: 「심화 첫걸음」(심화 1개), 「깊이 파는 사람」(심화 51개 전부).
- **점검기 규칙**: 심화 `n-Ak`는 **n장까지의 규칙 + 심화 전용 허용**. 심화에서 처음 여는 문법: 컴프리헨션(7장 심화), lambda(9장 심화), 기본값 매개변수·재귀(4장 심화), `match`(3장 심화), 특수 메서드 추가(15장 심화), JOIN은 SQL 글이라 제한 없음. 심화에서 연 문법은 **본 과정 레슨에는 계속 금지**(본 과정만 하는 학습자를 위해).

## 2. 매일 도전

- **모습**: 하루 한 번, 3문제(터치 2 + 직접 작성 1), 5분 안팎. 홈 화면 맨 위 「오늘의 도전」 카드.
- **문제 고르기**: 끝낸 장에서만. 틀렸던 개념(`review_queue`)이 들어 있는 장을 더 자주. 같은 날에는 누구에게나 같은 3문제가 아니라 학습자마다 다름(날짜 + 학습 기록으로 정하므로 다시 열어도 같은 문제).
- **문제 만들기(엔진)**: 문제 「틀」에 이름·숫자를 바꿔 끼워 매일 새 문제를 만든다. 틀은 장마다 4~6개, 정답은 실제로 실행해서 정한다(점검기가 틀마다 바꿔 끼운 결과 100가지를 미리 돌려 봄).
- **보상**: 3문제를 다 풀면 XP 15 · 바이트 10. 매일 도전 연속 기록(「도전 n일째」)을 따로 셈, 7일마다 바이트 +20. 기존 연속 기록·하루 목표에도 그대로 반영.
- **오프라인**: 틀은 장 파일에 들어 있으므로 비행기 모드에서도 됨.

## 4. 확인 방법

- 단위: 심화 열림 규칙(평가 전 잠김·통과 즉시 열림·건너뛰어도 다음 장 열림), 보상, 배지, 저장 옮기기(옛 저장은 심화 0개로 시작), 매일 도전 문제 고르기(같은 날 같은 문제, 끝낸 장에서만, 틀린 개념 가중).
- 점검기: 심화 규칙 허용·금지 샘플, 본 과정에 심화 문법이 새지 않음.
- 화면: 학습 길 가지·설정 「심화 n/3」·오늘의 도전 카드, 아이폰 17.
- 경제 시뮬레이션: 심화·매일 도전을 더한 하루 바이트와 첫 의상 날(3~4일째 유지), 마지막 의상까지 걸리는 날.
