# 경비실 v0.16.1 다듬기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 디버깅 시뮬레이션에서 나온 엔진 멈춤·보기 순서·판정 없음·오류 안내·약한 시도·화면 문제를 고친다.

**Architecture:** 엔진 쪽(`src/py/guard.py`, `src/py/runner.py`, `src/worker.js`, `src/pyrun.js`)은 판정 규칙·`builtins` 되돌리기·치명 오류 재시작을, 앱 쪽(`src/guard/*`, `src/ui/guard.js`, `src/grade.js`, `data/errors.js`)은 섞기·표시·오류 안내를, 데이터(`data/guard.js`, `i18n/en/*`)는 시도·정답 보완을 맡는다.

**Tech Stack:** 기존 그대로. 새 의존성 없음.

**Spec:** `docs/specs/2026-11-13-경비실-v0.16.1-다듬기-설계.md`

## Global Constraints

- 작업 브랜치는 로컬 `feature/guard-hardening`. **푸시·합치기 금지**(사용자 승인 뒤 컨트롤러).
- 첫 파일(`dist/index.html`) **850KB(870,400B) 미만**(G-C6). 지금 844,225B.
- 이미 푼 기록·XP·`saveVer` 2·`save.garden` 바뀌지 않음. 바이트 직접 지급 없음.
- 사건 시도는 덧붙이기만(기존 순서·`why` 번호 유지), 사건당 20개 이하. G1~G45 id 그대로.
- 코드 속 이름은 한·영 공통 영어. 화면 문구는 `t```, 영어는 `i18n/en/ui.*.json`·`data.json`(`i18n_coverage` 실패 0).
- 방어 쪽 코드만, `.example` 주소만, 리아 존댓말·크로우 반말.
- `README.md`는 `tools/readme_gen.py`로만.
- 판정은 `docs/plans/ledger.md`의 「v0.16.1」 표에 G3-C1 … 번호로.
