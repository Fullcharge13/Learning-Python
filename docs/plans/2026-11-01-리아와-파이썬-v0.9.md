## 판정(감독)

- **C53 직접 작성 문제는 기존 레슨에서 고른다**: 매일 도전의 터치 2문제는 「틀」에 이름·숫자를 바꿔 끼워 새로 만들고, 직접 작성 1문제는 학습자가 끝낸 레슨의 직접 작성 문제(숨은 시험 그대로) 가운데서 고른다. 직접 작성 문제를 자동으로 만들면 숨은 시험·하드코딩 방지까지 자동으로 만들어야 해서 채점이 흔들릴 위험이 크기 때문. 틀린 개념이 들어 있는 레슨을 더 자주 고른다.
- **C54 틀 형식**: 장 파일의 `TEMPLATES`(장마다 4개 이상). 틀 = 문제 종류(choice/blank) + 바꿔 끼울 값의 목록(이름·숫자 범위) + 코드·문제 문장의 자리 표시. 정답과 오답 선택지는 실제 실행 결과로 정한다. 점검기가 틀마다 100가지를 미리 만들어 돌려 보고, 오답이 정답과 같아지거나 오류가 나는 경우가 없는지 확인한다.
- 같은 날·같은 학습자는 다시 열어도 같은 3문제(날짜 + 학습 기록으로 정하는 난수).
