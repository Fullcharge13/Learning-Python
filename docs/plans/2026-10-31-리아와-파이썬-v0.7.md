# 「리아와 파이썬!」 v0.7 계획서 — 심화 엔진 + 1~6장 심화

**목표**: 장마다 심화 레슨 3개를 넣는 엔진(열림 규칙·학습 길 가지·보상·배지·점검기 심화 규칙)을 만들고, 1~6장 심화 18레슨을 쓴다.

**설계서**: `docs/specs/2026-10-31-심화학습-설계.md`(확정) · 작성 규칙: `docs/lesson-writing-guide.md`

## 데이터 형식

- 심화 레슨은 장 파일 `data/lessons/chN.js`의 새 목록 `ADVANCED`(레슨 3개, id `N-A1`~`N-A3`, `isAdvanced: true`)에 둔다. 장 파일 나누기·미리 받기는 그대로.
- 레슨 목록(index.html)에 심화 레슨의 id·제목·목표·개념을 함께 넣는다.
- 저장: `completed_lessons`에 `N-Ak`가 들어간다. 저장 형식은 그대로라 saveVer 변경 없음(옛 저장은 심화 0개).
