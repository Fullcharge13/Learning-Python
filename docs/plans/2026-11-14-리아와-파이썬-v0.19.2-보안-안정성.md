# 보안·안정성 다듬기 (v0.19.2) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 배포판이 파이썬 엔진을 같은 출처에서 받고(외부 요청 0), 화면에 HTML을 넣는 모든 곳이 학습자·파이썬·가져온 값을 escape하며, 흔들리던 오프라인 시험이 조건으로 기다린다.

**Architecture:** `build.py`가 배포판에 Pyodide 핵심 5개를 `dist/pyodide/`로 복사(지문 확인)하고 `RIA_PYODIDE_URL="./pyodide/"`를 넣는다. `sw.js`는 같은 출처의 엔진 주소를 저장한다. 출력 점검은 넣는 곳 목록 → 값 출처 분류 → 위험한 곳에 실패 시험 → 고침 → 점검표 문서.

**Tech Stack:** 기존 그대로. 새 의존성 없음.

**Spec:** `docs/specs/2026-11-14-보안-안정성-다듬기-설계.md`

## Global Constraints

- 작업 브랜치 로컬 `feature/hardening-2`(e188696에서). 작업 중 푸시·합치기 금지.
- Pyodide 판 그대로 `314.0.7`. 핵심 5개: `pyodide.mjs`, `pyodide.asm.mjs`, `pyodide.asm.wasm`, `python_stdlib.zip`, `pyodide-lock.json`.
- 배포판 `RIA_PYODIDE_URL = "./pyodide/"`. 개발·시험판(`--dev-pyodide`)은 `/node_modules/pyodide/` 그대로.
- 배포판의 어떤 파일에도 `cdn.jsdelivr.net` 없음.
- 기능·문구·저장 형식 변경 없음(`saveVer` 2). 첫 파일 600KB 한도.
- 점검표: `docs/security/2026-11-14-출력-점검표.md`.
- 판정은 `docs/plans/ledger.md`「v0.19.2」 표 H-C1…, 판정 C19(jsDelivr)는 「H-C1로 바뀜」 표시. `README.md`는 `tools/readme_gen.py`로만.
