# 밤의 연구 노트 (v0.19.0) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정에서 시스템 따라가기·밝게·어둡게를 고르고, 어둡게는 「밤의 연구 노트」 색으로 모든 화면의 글자 대비 4.5:1 이상을 지킨다.

**Architecture:** 기기 단위 설정 `localStorage["ria-python.theme"]`를 `src/index.html` 머리 스크립트가 CSS보다 먼저 읽어 `<html data-theme>`를 정하고, `src/theme.js`가 바꾸기·시스템 변화 따라가기를 맡는다. `src/style.css`는 `[data-theme="dark"]`에서 색 이름표를 다시 정의하고 직접 적은 색을 이름표로 바꾼다. 편집기 묶음은 `data-theme`를 지켜보는 `Compartment`로 문법 색을 바꾼다.

**Tech Stack:** 기존 그대로. 새 의존성 없음(CodeMirror `HighlightStyle`·`Compartment`는 이미 있는 패키지).

**Spec:** `docs/specs/2026-11-14-밤의-연구-노트-다크모드-설계.md`

## Global Constraints

- 작업 브랜치 로컬 `feature/tutorial-dark`(1ff486d에서). 작업 중 푸시·합치기 금지(컨트롤러가 마지막에).
- 설정 키 `ria-python.theme` ∈ `"system"|"light"|"dark"`, 없거나 이상하면 `"system"`. 학습 기록 저장에 넣지 않음. `saveVer` 그대로.
- `<html data-theme="light"|"dark">`, `color-scheme`도 같은 값. `<meta name="theme-color">` = 밝게 `#FBF6EA`, 어둡게 = 어둡게 `--paper`.
- 어둡게 시작 값(설계서 §3-2 표) — `--paper #141C2B`, `--paper-2 #1B2538`, `--card #1E2940`, `--line #34425E`, `--ink #F1EBDD`, `--ink-2 #B7BFCD`, `--navy #0E1522`. 대비 시험으로 다듬을 수 있음.
- 대비 기준: 글자 ≥ 4.5:1, 큰 글씨(24px 이상, 또는 굵게 19px 이상) ≥ 3:1. **어둡게는 실패시킴, 밝게는 미달 목록만 보고.**
- **밝게는 지금과 같음**: 밝게에서 계산된 색 값·스크린숏이 바뀌면 안 됨. 어둡게 전용 고침은 `[data-theme="dark"]` 아래에서만.
- 그림(`data/ria_set2.js`, `data/crow.js`, 배지·의상 그림, 텃밭 밭·작물 그림)의 색은 손대지 않음. 텃밭 SVG 안 말풍선·글자는 CSS 변수를 따름.
- 문구: 설정 「화면」 · 「밤에는 어두운 화면이 눈이 편해요」 · 「시스템 따라가기」 · 「밝게」 · 「어둡게」 (영어 Display / "Easier on the eyes at night" / System / Light / Dark — 영어는 `i18n/en/ui.*.json`).
- 첫 파일 600KB 한도, 편집기 묶음 420KB 한도. `README.md`는 `tools/readme_gen.py`로만. 판정은 `docs/plans/ledger.md`「v0.19.0」 표 D-C1….
