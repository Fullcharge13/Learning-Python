# 「리아와 파이썬!」 v0.2 계획서 — 4~6장(함수·반복문·문자열)

**목표**: 4장 함수, 5장 반복문, 6장 문자열 다루기의 레슨 15개를 더해 모두 30개 레슨으로 늘린다. 그리고 7~17장에서도 그대로 쓸 「레슨 작성 키트」(가이드, 장별 문법 표, 체크리스트)를 완성한다.

**구조**: 엔진(화면·채점기·규칙)은 바꾸지 않는다. 바뀌는 것은 데이터(`data/lessons/ch4~6.js`, `data/concepts.js`)와 점검기(`tests/content.py`)의 장별 표뿐이다. 설정의 「학습 내용」 카드와 학습 길 끝 문구는 데이터에서 자동으로 바뀐다(C33).

**기술**: 기존과 같다. 레슨 초안은 Sonnet 일꾼이 쓰고, 검토와 최종 판정은 Opus가 한다(커리큘럼 결정 ④).

**설계서**: `docs/specs/2026-10-30-커리큘럼-4-17장-초안.md`(확정), 원 설계서 `docs/specs/2026-10-29-리아와-파이썬-설계.md`

**전역 제약**
- 레슨 형식, 글자 수 제한, 장별 허용 문법은 `tests/content.py`가 기준이다. 일꾼은 오류가 0이 될 때까지 혼자 고친다.
- 장마다 레슨 5개를 두고, x-5는 장 평가다. 터치 문제 4~6개(평가는 4~8개), 직접 작성 1개, 이해도 확인 1개를 둔다.
- 직접 작성 문제는 `input()`이 있으면 시험 2~4개(공개 1개), 없으면 공개 시험 1개를 둔다(C20). 하드코딩은 `require`로 막는다(`Call:`/`Name:` 형식, C26).
- 문장은 새로 쓰고 책 문장을 옮기지 않는다. 리아 교수의 「~해요」체를 쓰고, 연애 느낌의 표현은 쓰지 않는다. str은 「문자열」로 부른다.
- 커밋·푸시·배포는 사용자 허락을 받은 뒤에만 한다.

**검토 중점**
1. 함수 장의 하드코딩: `def`는 만들었지만 결과를 함수 밖에서 계산해 출력하는 답 → 작업 3: 시험 입력을 여러 개 두고 `Return`·`Name:<매개변수>`를 require로 건다.
2. 반복문 장의 경계값: `range` 끝값, 0회 반복, 입력 n=1 → 작업 4: 숨은 시험에 n=1과 n=0(또는 최솟값)을 반드시 넣는다.
3. 정답 코드 안의 무한 반복: 점검기 5초 제한으로 잡힌다 → 작업 2: 점검기 시험 `loop_timeout`.
4. 문자열 장의 인덱스 범위: IndexError 문제의 정답 유일성 → 작업 5: 터치 문제를 실제로 실행해서 확인(점검기가 자동으로 함).
5. 레슨 수가 30개로 늘었을 때 경제 균형: 첫 의상 날짜, 하루 목표 → 작업 7: 시뮬레이션을 실제 레슨 수로 다시 돌린다.

## 작업 2. 점검기와 개념 표 확장 (Opus 일꾼)

**파일**: `tests/content.py`, `data/concepts.js`, `tests/content_rules_test.py`(새 파일)
**만드는 것**:
- `CHAPTERS_EXPECTED`를 고정값(3) 대신 「있는 장 파일이 1부터 빠짐없이 이어지는지」 검사로 바꾼다. `--full`은 「계획한 장 수」를 인자로 받는다(`--full 6`).
- 장별 표: `FORBID_BY_CHAPTER`·`NAMES_BY_CHAPTER`·`CALLS_BY_CHAPTER`에 4·5·6장 추가
  - 4장: `FunctionDef`, `Return` 허용. 반복문·리스트 금지
  - 5장: `For`, `While`, `range` 허용. 리스트 리터럴 금지(`split` 결과는 허용하지 않음)
  - 6장: 인덱싱·슬라이싱·문자열 메서드 허용. `split()` 결과를 `for`로 도는 것까지 허용하고, 리스트 리터럴은 7장부터
- `concepts.js`에 4~6장 개념 id 추가: `call`, `def`, `param`, `return`, `while`, `for`, `range`, `accum`, `break`, `index`, `slice`, `strmethod`, `strloop`
- [ ] 시험(먼저 작성): 장별 허용·금지 샘플 9개(각 장마다 허용 1·금지 2) → 기대 판정. 정답 코드에 `while True: pass`가 있으면 「5초 초과」 오류로 보고(`loop_timeout`)
- [ ] 구현
- [ ] 확인: `python3 tests/content_rules_test.py` 통과, `python3 tests/content.py --full 3` → 1~3장 오류 0(회귀 없음)
