# 경비실(사이버 보안 배우기) v0.15.0 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 파이의 텃밭 안에 「경비실」을 더해, 3~6장을 끝낸 학습자가 방어 코드를 쓰고 가상 공격 재생으로 확인하는 보안 사건 6개를 한·영으로 플레이하게 한다.

**Architecture:** 판정 규칙은 새 `src/py/guard.py` 한 곳에 두고 `runner.run(..., guard=)`이 부른다(텃밭 `farm=`과 같은 길). 배포·개발·시험 모두 `runner.py + guard.py`를 이어 붙인 한 파일을 Pyodide에 올린다. 화면(`src/ui/guard.js`)은 엔진의 사건 기록을 재생만 하고, 저장은 `save.guard`로 텃밭과 따로 둔다.

**Tech Stack:** 기존 그대로 — Pyodide 314.0.7, 바닐라 JS(ES 모듈, esbuild 묶음), CodeMirror 6, `node --test`, pytest, Playwright Chromium. 새 의존성 없음.

**Spec:** `docs/specs/2026-11-12-경비실-설계.md`

## Global Constraints

- 브랜치 `feature/guard-room`에서만 작업. main 건드리지 않음.
- 첫 파일(`dist/index.html`) 820KB 미만, `data/crow.js` 15KB 이하.
- `saveVer` 2 그대로. `save.garden`·텃밭 주문·텃밭 시험은 바꾸지 않는다.
- 코드 속 이름은 한·영 공통 영어: `attempt`, `password`, `block()`, `allow()`, `has_try()`, `next_try()`, `check`.
- 화면 문구는 모두 `t```로 감싸고 영어는 `i18n/en/ui.guard.json`, 데이터 문구 영어는 `i18n/en/data.json`의 `guard.*` 열쇠.
- 사건 첫 해결에만 XP 5. **바이트는 어떤 경로로도 주지 않는다.**
- 시도는 사건당 1~20개, 실행 시간 제한은 기존 3초.
- 크로우 그림 안 `<text>` 금지. 6포즈 이름: `wave` `wait` `shock` `loot` `cry` `rank`.
- 방어 쪽 코드만. CarterPerez-dev/Cybersecurity-Projects(AGPL-3.0)의 코드·문구를 가져오지 않는다.
- 터치 대상 44pt 이상(기존 `flow.py` 기준).
- `README.md`는 손으로 고치지 않는다(`tools/readme_gen.py`).
- 판정(구현 중 결정)은 `docs/plans/ledger.md`에 「v0.15」 표로 G번호(G-C1, G-C2 …)를 매겨 기록한다.

## Review Focus

1. **학습자가 엔진 이름을 덮어씀** — `check = 3`, `def check(): …`(인자 없음), `block = None` 뒤 `block()`. 기대: 앱이 멈추지 않고 그 줄을 가리키는 오류 안내. → 작업 2 `test_check_not_callable`, `test_check_wrong_arity`, `test_block_shadowed`.
2. **사용 오류를 except로 삼킴** — `while True: try: next_try() except: pass`처럼 쓰면 시도 없는 `next_try()` 오류를 삼키고 계속 돈다. 기대: 시간 초과가 아니라 「더 이상 시도가 없어요」 오류로 끝남. → 작업 2 `test_swallowed_usage_error_reported`.
3. **숫자 시도 값의 왕복** — G2의 `attempt`는 정수여야 `attempt >= 9`가 된다. JSON → Pyodide → 결과 대조까지 정수가 유지되고, 영어판 G5 값(`"order 1"`)으로도 대조가 맞아야 함. → 작업 2 `test_int_attempt_stays_int`, 작업 6 `guardConsistent: en 값으로 대조`.
4. **이상한 저장 가져오기** — `guard: { solved: "yes", blanks: { G1: [99, "x"] }, seen: [1, "G9"] }`. 기대: 앱이 열리고 잘못된 칸만 기본값/`null`로, 모르는 id는 버림. → 작업 6 `cleanGuard: 망가진 값`.
5. **재생 중 다시 실행·화면 떠나기** — 재생 도중 「실행」을 다시 누르거나 사건을 바꾸면 이전 재생이 새 화면에 그림을 그리면 안 됨. 기대: 재생 중 「실행」 비활성, 화면을 떠나면 재생 타이머 정리. → 작업 7 `flow.py` 단계 「재생 중 실행 단추 비활성·사건 바꾸면 결과 비움」.
