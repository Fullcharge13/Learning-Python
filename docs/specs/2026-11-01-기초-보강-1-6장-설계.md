# 1~6장 기초 보강 설계 (리아와 파이썬! v0.7.1)

- 작성일: 2026-11-01 · 상태: **확정**(2026-11-01, 사용자 「확정 · 진행」)
- 배경(사용자 피드백): 「심화학습에서 나오는 개념이 기본 학습루트에서 배우지 않은 부분이 나오다 보니 조금 어려운 부분이 있습니다.」
- 사용자 결정: **기존 레슨에 카드·문제 보강**(레슨 수·번호 그대로)

## 1. 무엇이 비어 있었나 (본 과정 1~6장과 심화 비교)

| 심화 | 심화가 기대는 기초 | 본 과정 상태 |
|---|---|---|
| 1-A1~A3 | f-문자열(`f"{3 * 4}개"`) | 본 과정에서 정식으로 안 가르침(3장부터 그냥 등장) |
| 2-A1 | 실수(소수)와 `round` 기본 | 실수는 짧게, `round`는 4장에서 처음 등장 |
| 3-A1·A3 | 조건의 결과가 True/False라는 것, 조건을 변수에 담기 | 안 다룸 |
| 4-A1·A3 | 이름 붙여 부르기(`f(price=5000)`), 함수 안에서 다른 함수 부르기 | 안 다룸 |
| 5-A1·A3 | `print(..., end="")`, 반복 안의 반복 | 안 다룸 |
| 6-A1·A2 | `zfill`·`center` 같은 「모양 맞추기」 메서드 | 안 다룸 |

`match`, 재귀, `for…else`, 서식 지정자(`:>8`)처럼 **심화 레슨이 직접 가르치는 주제**는 그대로 심화에 둔다. 비는 것은 그 앞의 디딤돌이다.

## 2. 보강 위치 (레슨마다 카드 1장 + 터치 문제 1~2개)

| 레슨 | 더하는 내용 |
|---|---|
| 1-2 문자열 다루기 | f-문자열 기초: 따옴표 앞 `f`, `{}` 안에 계산 넣기 |
| 2-2 값의 종류, 자료형 | 실수 계산 결과가 길어지는 모습, `round(값, 자릿수)` 맛보기 |
| 3-4 and·or로 조건 묶기 | 조건 자체가 True/False 값, `ok = a >= 60 and b >= 60`처럼 담기 |
| 4-3 매개변수 | 이름 붙여 부르기(`price(won=5000)`) |
| 4-4 결과 돌려주기 | 함수 안에서 다른 함수 부르기 |
| 5-2 for와 range | `print(i, end=" ")`로 한 줄에 이어 찍기 |
| 5-3 합계 모으기 | 반복 안의 반복 맛보기(작은 별 직사각형) |
| 6-3 문자열 메서드 | `zfill`·`center`로 모양 맞추기 |

- 직접 작성 문제는 바꾸지 않는다(기존 채점·하드코딩 방지 유지). 장 평가(x-5)도 그대로.
- 점검기: 본 과정 규칙에서 위 문법을 그 장부터 허용(f-문자열 1장, `round` 2장, 키워드 인자 4장, `end=` 5장, `zfill`·`center` 6장). 서식 지정자·`match`·재귀 등은 계속 심화 전용.
- 심화 레슨 첫 카드에는 「본 과정 n-m에서 본 ○○를 기억하나요?」 한 줄을 넣어 이어 준다.

## 3. 이미 끝낸 학습자

- 보강된 레슨을 이미 끝냈다면 학습 길 노드에 작은 **「새 내용」 점**을 띄운다. 다시 하기로 열면 점이 사라진다.
- 다시 하기 보상은 기존 규칙(XP 10, 바이트 0). 진도·연속 기록·배지에는 영향 없음.
- 레슨 목록에 레슨별 `updated`(보강된 판)를 두고, 저장에는 「다시 본 판」만 기록(saveVer 그대로, 없으면 빈 값).

## 4. 확인

- 점검기: 보강된 8레슨 오류 0, 보강 문법이 앞 장에 새지 않음, `--full 17 --advanced 6` 회귀 없음.
- 단위: 「새 내용」 점(끝낸 레슨 + 갱신됨 + 아직 안 봄일 때만), 다시 하기 뒤 사라짐, 옛 저장.
- 화면: 점이 뜬 학습 길, 보강 카드(아이폰 17).
- 검토: 보강 카드만 보고 심화 A1을 풀 수 있는지(디딤돌이 이어지는지) Opus 검토자가 확인.
